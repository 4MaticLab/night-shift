# 《面包奇谈》故事圣经

本文件固定 CASE 003 的人物关系、案件因果和结局边界。运行时生成能力、睡眠硬件、好友线索与玩家路线都只能丰富叙事，不得改写这些事实。

## 核心谜面

雾灯城煤钟街的一家十二人合作面包房在十七年前被没收并停业，街边保温柜却仍在每天黎明前多出第十三只面包。工资簿、围裙、工作台和十二枚黄铜持份环都证明合作社从未有第十三名成员。

第十三只面包不是失踪者的份额，也不是秘密利润。它是合作社章程中的“访客份额”：每天必须为当夜无力支付的人留下的一份早餐，不登记领取者、不要求回报，也不附带投票权或所有权。

## 固定真相

- 合作社始终只有十二名持份人；完整名册没有被删掉的第十三行。
- 十七年前的火灾由炉桥下市政热力主管超压引起，不是面包炉违规。熔断器、向内展开的焦痕和费澄未提交的修正页互相印证。
- 市政报告把公共设施责任转嫁给合作社，并以此没收房契。
- 合作社没有因没收而消失。十二名成员与邻居把母酵分散在多户窗台，夜间轮流送到地下公共炉；夜账只记录劳动，不设方便被处罚的唯一负责人。
- 柯遥根据诊所、候车室与街边柜当夜的需要决定第十三只面包的去向。这条路线不收费，也没有固定私人终点。
- 完整归还必须同时承认两种权利：十二名成员重新获得合作社所有权；访客份额成为不可出售、不可取消且不由私人代持的公共使用权。

## 五夜节奏

1. **柜中多出的一只**：确认每天确有第十三只面包，但柜边只有十二枚持份环磨痕，领取者也不固定。
2. **没有第十三名烘焙师**：十二人名册与空白访客牌证明“多出来的一份”属于制度，不属于隐去的人。
3. **火从炉外开始**：用熔断器、焦痕、完整砖炉与修正页还原市政热力主管超压。
4. **整座街区保管一块酵母**：发现分散母酵、无负责人夜账和免费送达线，确认合作社以共同劳动延续。
5. **把一份归还给无人**：修复房契与章程，决定怎样同时归还十二人所有权和无主访客权利。

## 关键人物

- **宋岑**：合作社账房与烘焙师。保存完整名册、持份环和空白访客牌；仍参与地下公共炉轮值，但拒绝成为市政可以单独追责的领袖。
- **费澄**：退役市政热力检察员。最初签过错误报告，后来写出认定主管超压的修正页，却在上级压力下没有提交。
- **柯遥**：夜间免费送达线骑手。收集分散母酵并按当夜需要配送访客面包；她不是某家店的私人送货员。
- **何砾**：市政档案修复师。受命修复待拍卖房契，却保留第十三栏原有的空白，寻找不会把公共权利变成私人代持的法律写法。

## 三条核心推理

- `twelve-name-roster + blank-guest-share`：第十三只面包不是失踪成员的份额。
- `conduit-scorch + corrected-inspection`：火灾由市政热力主管超压引起。
- `starter-census + night-bake-ledger`：合作社通过分布式酵母与轮值劳动继续存在。

## 密文与最终接线

三组可选密文依次确认每日数量 `13`、火灾方向“市政热力主管”和公共权利代码 `COMMON`。全部归档后，最终接线按 `CAUSE → OWNERS → RIGHT` 排列：公共管道责任、十二名所有者、无主公共使用权。密文只展开旁注，不改变联合推理或结局资格。

## 三种结局

- **把火灾报告贴满全城**：公开纠正责任并归还房契，但让地下互助网络受到额外关注。
- **先保住地下公共炉**：先保全关键证据并维持路线低调，等待十二名成员准备好走进白天。
- **让第十三栏永远空白**：真结局。房契归还十二人，访客份额写成永久公共使用权，不登记未来领取者。
