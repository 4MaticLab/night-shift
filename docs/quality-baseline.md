# 当前质量基线

## 已验证能力

- 五夜确定性案件内容、12 条线索、8 件收藏品。
- 三种睡眠质量都推进主线，安稳睡眠提供更完整内容。
- 三件随身物为每夜提供不同环境回响，但不改变固定线索。
- 五枚夜印随完成章节积累并通过本地存档保留。
- 五张城市明信片分别对应五夜地点；晨报先展示归来旅程，收藏页按完成报告永久解锁旅程册。
- 三件随身物会为每张明信片留下不同背面附言，章节事实与线索保持不变。
- 五夜共有十五条确定性调查方向；每条拥有独立路线、五段夜间事件、城市遭遇和归来来信，而同章节固定线索与藏品不分叉。
- 五株章节专属夜生植物拥有独立植物学版画、四阶段成长文案与三种睡眠层级说明；断续睡眠仍生成完整植株，不存在枯死或失败状态。
- 十五条方向各自惊动错页登记处、失物领事馆或熄灯测绘社之一，三个社团各覆盖五条路线；跨夜关注只改变三层称呼、来函和礼数，不改变奖励或结局。
- 三个社团均拥有原创 1:1 档案纹章、公共传闻、内部规矩与可回看的城市人情簿。
- 三个社团的三层关系各有一个问函，共九问、十八种答复；每类总体姿态各六种。玩家可以答 A、答 B 或不回信，固定奖励和后续章节都不受影响。
- 同一社团的后续来函只引用该社团最近一次已答问函；问函、答复与余波进入城市人情簿，结局完成后只显示一条非资格型城市附言。
- 九件口袋纪念物各有独立 1:1 蚀刻资产、城市传闻、来历与林渡短笺；三个社团和三件随身物各覆盖三件。
- 十二张白天机会告示包含二十四种无评分答复；第一夜后的四个白天各稳定展示三张，回应或全部收起都不阻断主线，选择会在次晨回声并进入剪报册。
- 米娜、吉迪恩、奥林与伊芙琳拥有四张统一的 4:5 编辑蚀刻肖像；第 2–5 夜晨报各揭示一人，档案页按已完成报告与既有证物分层展示人物事实。
- Demo 固定旅程种子，真实新档生成并持久化本地种子；方向、随身物和既有历史稳定选择小物，五夜不重复、刷新与旧档迁移不重抽。
- 八件收藏品均使用独立的编辑蚀刻插画，不再以字符作为主要视觉。
- 首页、三幕开场、睡前交接、12 秒夜间模拟、可恢复的真实夜班、晨报、案件板、收藏和三个结局。
- Zustand 浏览器本地存档与 v9 迁移；除既有夜间历史外，`opportunityHistory` 独立保存白天展示、选择或收起快照，Demo 抽屉和 `Shift + D` 快捷键可生成可解释的默认履历。
- 真实夜班以持久化开始时间结算；关闭页面再返回仍能恢复进度，晨报会显示实际时长与派生质量。
- 产品界面已按落地叙事、夜间循环、调查归档和导航框架拆分；`app/page.tsx` 只负责编排。
- 案件板要求玩家选择两件证物建立关系；三条核心推论由确定性证物对校验，错误连接不会写入存档。
- 自动测试已覆盖十五条方向完整性、社团均匀映射与固定奖励护栏、三层关系累计、九问十八答平衡、同社团最近答复查询、九件纪念物分布、稳定选择与五夜无重复、四位人物的章节／资产／证物契约、无答复继续、五株植物内容与四阶段边界、安稳睡眠的完整五夜循环、真实夜班持久化重载、旧存档温室／关系／纪念物历史重建、三个结局与真结局门槛。
- 服务端可渲染产品标题与社交分享元数据。

## 验证命令

```bash
npm test
npm run lint
npm run build
npm run test:render
npm run docs:check
```

Playwright Happy Path 位于 `tests/e2e/night-shift.spec.ts`：分别覆盖 Demo 方向事件与植物成长、晨报纪念物揭示与无优势说明、首封问函答复、同社团后续余波、归来明信片、城市人情簿与答复履历、口袋抽屉、雾灯温室、真实交接刷新恢复和两证物核心推论。`tests/game-store.test.ts` 在内存浏览器存储上覆盖五夜方向、随身物、成长、关系、答复与纪念物历史、无答复继续、迁移、恢复与结局。浏览器测试使用本机 Chrome channel，避免依赖额外下载的 Playwright 浏览器。

## 已知边界

- 浏览器端视觉回归、完整五夜 E2E 和移动端交互尚未纳入自动验证。
- 直接运行原生 `tsc --noEmit` 会缺少 Cloudflare Worker 全局类型；项目正式的 Vinext 生产构建不受影响。

完成的工程加固见 [[plans/0003-mvp-quality-hardening]]；当前时间成长升级见 [[plans/0007-night-greenhouse-and-time-growth]]。

桌面与移动端人工核对项见 [[docs/viewport-checklist]]。
