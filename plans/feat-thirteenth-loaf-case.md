## 动机

当前案件书架只有《零点四十三分的末班车》和《只在雨中播出的电台》。第二案虽然证明案件 manifest 可以复用主循环，但其人物为空、视觉仍复用第一案资产，尚不足以证明“完整的新剧本 + 独立美术”可以作为 Night Shift 的长期扩展单元。

第三案以“十二人合作面包房为何每天留下第十三个面包”为谜面，继续讨论城市档案、共同所有与被行政抹除的人情制度。它不改变玩家与林渡的分工：玩家白天分析，睡前决定调查方向，林渡在玩家离开页面或睡眠时完成夜班，清晨带回固定事实。

## 范围

- 新增技术 ID 为 `case-004`、书架档案号为 `003` 的完整五夜案件《黎明前出炉的第十三个面包》。
- 编写故事圣经，固定人物关系、火灾责任、合作社份额和“第十三个面包”的真实用途。

- 生成并接入本案专属美术：四幕横幅、五枚夜印、五张明信片、五张植物标本、八件收藏品、四张人物肖像、三张城区版画，共 34 张。

## 验收标准

- 案件书架显示三宗案件，默认案不变；第三案可进入、切出、刷新并恢复独立进度。
- 第三案严格完成五次“交接 → 夜间 → 晨报”，可在案件板完成三条联合推理和三组密文，最终到达三种结局。
- 真结局仍要求亲自取得全部线索、至少 7 件收藏品和全部 3 条关系；好友线索不替代亲自调查。
- 所有引用 ID 经过 schema/manifest 校验，线索、收藏、人物与关系不跨案件泄漏。
- 34 张专属资产均被 manifest 或档案页面实际消费，构图和配色与现有 Literary Storybook Noir 统一，无可读文字、水印、品牌或现成作品角色。
- 首页和关键流程在 1440 × 900、820 × 1180、390 × 844 无横向溢出、不可达主操作或明显裁切。
- 稳定文档与实现一致，临时计划完成后按规范退役并保留 Git 历史。
