## 动机

当前导航仅用文字 `NS` 作为临时标记，浏览器图标仍是与项目无关的默认图形。项目已有稳定的 Literary Storybook Noir 美术语言，需要一枚能在导航、favicon 与品牌物料中复用的原创 Logo 图形。

## 范围

- 通过生图模型生成一枚无文字、透明背景、可在小尺寸辨认的 Night Shift 品牌图形。
- 在现有品牌标记和站点元数据中接入该图形。
- 更新资产清单与视觉说明，记录文件和使用边界。

## 非目标

- 不重新设计首页布局、标题字体或完整品牌手册。
- 不生成含模型绘制中文的锁定字标。
- 不改变案件内容、交互流程或产品方向。

- [x] 通过生图模型生成并检查透明背景 Logo 图形。
- [x] 接入导航品牌标记与站点图标。
- [x] 更新资产文档与生成提示词记录。
- [x] 运行文档、测试、lint 与构建验证。

## 验收标准

- Logo 延续深夜城市、暖琥珀灯、旧铜与编辑蚀刻的原创语言。
- 42px 导航尺寸与小尺寸站点图标中仍保有清晰轮廓。
- 透明背景无明显色键残边，且不依赖图片内文字表达品牌名。
- 现有中英文品牌文字、按钮语义与响应式布局保持不变。

## 验证

- 人工检查源图与透明 PNG 的边缘、色彩和小尺寸可读性。
- `npm test`
- `npm run lint`
- `npm run build`
- `npm run docs:check`
