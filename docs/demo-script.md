# 90 秒现场演示

1. 0–15 秒：主页说明“你睡着以后，他才开始工作”，快速切换案件书架中的两张剧本卡，指出它们拥有独立进度；选回 CASE 001，点击“开始第 001 宗案件”。
2. 15–35 秒：三幕开场后选择“让纸张先开口”；林渡肖像旁的“今晚交接单”会立即写下“纸张的证词”、灯港旧票据工坊与当前随身物，方向卡同时提示可能惊动“错页登记处”。再带上“黄铜侧照灯”，在“放下纸条”写入“演示还没准备完，但今晚先到这里”，主动开启 AI 晨间短笺并指出最小数据说明，然后点击“今晚交给你了”。夜间会显示夜半城市侧影、逐渐显影的夜印和从纸底向上生长的票根灯蕨。
3. 35–55 秒：晨报先展示放下纸条与林渡回信；有模型时标注“AI 个性化短笺”，无密钥时当场展示“本地回信”，两者都不影响案件事实。再快速扫过城市明信片、完整票根灯蕨和“提前醒来也不会枯死”的说明，随后展示随身物回响、侦探日志、旧车票与“七年旧纸 / 昨天日期”的矛盾。
4. 55–75 秒：用底部导航打开案件板。先在夜班密文台打开第一关，把倒置的 `34 · 00` 还原为 `00:43`，现场展示即时回执与“答错不惩罚”；随后点击“四十三天”和“未寄出的明信片”，建立连接并确认“米娜知道伊芙琳仍然活着”。
5. 75–90 秒：按 Shift+D 打开 Demo，选择“跳到真结局条件”，完成第五夜并展示真结局。终函之后快速扫过“五夜归来总账”和实际物证，再点“重看档案／回到结案页”，说明旅程结果不是一次性统计画面，而是一份可回看的结案卷宗。

现场路径另有双案件浏览器护栏：首案与《只在雨中播出的电台》都从新档连续完成五夜并进入各自结局；另有案件感知分享／存档隔离路径，以及 390 × 844 的案件书架、首夜、收藏、档案、案件板和结案卷宗检查。演示时若临时切到第二案，仍处在已验证路径内。

## 真实夜班补充演示

若需要说明长期玩法，在第二步切换到“今夜真实交接”：界面会按设备本地时间预告掌灯、夜半、末更或白昼小憩。开始后点击“我只是醒了一下”，睡隙纸条出现但夜班不会结束，同一夜按钮随即锁定；刷新页面，夜班会连同原交接时间、时辰和这条回声恢复。点击“我醒了，拆开报告”后，晨报展示实际记录时长、该时辰独有的场景以及睡隙短笺。提前结束仍会获得主线线索，时辰与醒转也不会改变睡眠评价。

若要在 90 秒内演示施工单中的断续睡眠回声，在交接页选择“断续”再启动 Demo；直接跳到清晨也会看到本夜固定的睡隙卡。普通和安稳 Demo 不显示该卡，空白不是遗漏或较差结果。

若需要说明跨夜城市记忆，在 Demo 中跳到第三夜并完成“替307号房完成退房”：错页登记处的第三封来函会先引用上一封答复的余波，再提出新的问题。随后打开“收藏”，城市人情簿会显示两次默认答复、对应问函和即将进入后续来函的余波；页面不会显示声望分数。

若需要说明旅行式意外成果，完成任意一夜后在晨报停留“口袋里多出来的东西”：它明确不提供案件优势。再打开“收藏”的口袋抽屉，可以看到已归来的小物、当夜路线、随身物与林渡短笺；Demo 跳章会使用固定种子，因此每次演示保持一致。
