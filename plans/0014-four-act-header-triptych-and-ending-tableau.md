## 动机

当前首页、睡前桌面与晨报重复使用同一张偏数字绘景的主视觉；夜间探索只有 CSS 地图，结局只靠电车图标与光晕。它们功能完整，却没有形成“交接—夜行—归来—裁决”的视觉章节，也与近期建立的暖纸铜版蚀刻人物、城区和物件媒介存在质感断层。

本轮建立四张原创横幅：交接主视觉、夜间探索、晨间归来和隐藏站台结局。前三张分别承担原始验收中的三张核心页头图，第四张关闭结局插画缺口；首页画面同时给林渡一个统一、清晰的半身／全身轮廓。

## 范围

- 生成四张统一暖纸蚀刻媒介、不同时间色温与构图职责的原创横幅。
- 用新版交接画面替换旧首页与睡前复用图；夜行页增加克制背景画面但保留 CSS 路线与成长信息优先级。
- 晨报使用独立黎明归来图；结局选择与结局揭示共用隐藏站台画面并采用不同遮罩。
- 全部资产进入 manifest，补齐提示词、素材清单、响应式与自动化验证。

## 非目标

- 不复制现成游戏的角色、城市构图、黑色边框、菜单或专有地标。
- 不让插画承载可读文字、案件新事实、结局差异或可点击热区。
- 不移除夜间路线图、夜印成长、晨报内容或结局文本。
- 不为三个结局各生成一张不同“正确答案”插画。

## 验收标准

- 首页、夜行和晨报分别使用独立 manifest 页头资产，结局使用第四张正式插画。
- 林渡在交接与夜行画面中保持深色旧外套、灰蓝围巾、肩包、小手电与笔记本的统一造型。
- 插画在桌面提供足够文案负空间，在移动端裁切后仍保留主行动轮廓；文字对比度不依赖图像自身明暗。
- 夜间地图、报告标题与结局文本仍是交互和叙事第一层，图像不遮挡点击或阅读。
- 原始美术验收的侦探立绘、三张核心页头图与结局页插画由正式资产满足。

## 决定记录

- 2026-07-23：第十五版后按 Tier A 复盘，最大视觉缺口不是更多小物，而是核心流程缺少分幕。选择四张而非三张：前三张严格对应核心页头验收，结局保持独立画面，避免再次把同一图重复充当多个叙事时刻。
- 2026-07-23：四张图以第一张交接画面冻结林渡造型，后续用成图参考保持人物和媒介连续；页面通过独立 CSS 遮罩保证文字对比，图像不接管任何交互。
- 2026-07-23：浏览器回归发现通用图层规则把夜间顶栏从绝对定位覆盖为相对定位，真实夜班“醒来”按钮被标题截获；已缩小选择器职责并为顶栏建立独立交互层。内容测试 37/37、Playwright 7/7、lint、生产构建、服务端渲染和双链检查通过。
