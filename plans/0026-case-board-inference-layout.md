# 0026 — 案件板联合推理布局整理

- 状态：`completed`

- 更新：2026-07-23

- 推进模式：`auto`

## 动机

当前桌面案件板把两个证物槽与“核对这两件证物”按钮横向铺满在画布上沿，按钮落在右上区域，与证物配对关系及操作顺序脱节，也压缩了证物画布和右侧档案的可读空间。用户希望重新排布，让页面层级和推理路径更清楚。

## 范围

- 把两个证物槽和核对动作整理为明确的 A → 核对 → B 配对工作区。
- 压缩联合推理栏的垂直占用，并重新对齐右侧证物档案。
- 保持手机端顺序清晰、按钮易点击，且不破坏案板纵向滚动。
- 增补布局语义与关键交互回归。

## 非目标

- 不修改证物内容、合法配对、推论数量或结局条件。
- 不修改 React Flow 的拖动、缩放与持久化行为。
- 不改动仓库中正在进行的路线动画调整。

## 任务

- [x] 重排联合推理栏的结构与桌面样式。
- [x] 调整移动端布局与证物档案位置。
- [x] 更新自动化断言和稳定文档。
- [x] 运行与风险相称的完整验证。

## 验收标准

- 桌面端“核对”位于两个证物槽之间，视觉上明确表示配对操作，不再悬在页面右上方。
- 未选择、已选择一件、已选择两件及反馈状态均有稳定且清楚的布局。
- 390 × 844 下证物槽与核对按钮按自然阅读顺序纵向排列，无横向溢出，案板仍可纵向滑出。
- 既有关系匹配、证物移除、错误恢复和成功推论不变。
