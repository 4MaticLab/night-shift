# Night Shift background music asset

The project-owner-supplied MP3 is stored at:

`public/audio/c-minor-nocturne.mp3`

The runtime URL is `/audio/c-minor-nocturne.mp3`. Keep that file name when replacing the track so no code change is required.

Recommended delivery:

- MP3, 44.1 kHz or 48 kHz, stereo.
- Seamless loop with no long silence at either edge.
- Normalize conservatively; the runtime applies volume `0.22`.
- Keep the final web file reasonably compressed and record the source/license outside `public/`.

Do not commit an unlicensed or temporary commercial recording. Until the MP3 exists, the global control remains visible and reports that the track is waiting for upload; all pages continue normally.
