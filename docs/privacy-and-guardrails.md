# 隐私与健康数据护栏

## 数据边界

- 当前睡眠硬件数据只保存在浏览器本机的 `night-shift-sleep-hardware-v1`。
- 存档最多保留最近 8 条会话摘要，不保存逐分钟心率、呼吸、动作或睡眠分期曲线。
- 当前版本不上传健康数据，不建立账号，不请求厂商 OAuth，不保存 API 令牌。
- 权限按信号类别展示；“入睡与醒来时刻”是建立设备夜班的最低字段，其他字段可取消。
- 撤销授权会停止活动设备采集并清除授权状态；案件夜班继续运行。

## 产品表达

虚拟硬件读数是交互模拟，不是医疗设备数据。晨报必须标注虚拟样机、置信度与“非医疗结论”。真实厂商入口在实际 SDK 与权限闭环完成前只能称为“桥接预演”，不能使用“已连接”“同步成功”或其他会让玩家误认为真实数据已被读取的措辞。

睡眠摘要不得用于诊断、治疗建议、危险告警、雇佣或保险判断。睡眠质量和任何设备指标都不得减少线索、污染人物状态、锁定结局、制造失败或形成排行榜。

## 未来真实接入门槛

真实设备桥接至少需要：厂商最新文档复核、最小权限评审、令牌不落前端、撤销与删除路径、离线／无数据状态、数据保留周期、平台商店隐私声明，以及真实设备与模拟数据的视觉隔离。任何新增上传、账号或云同步都必须建立新的 `manual` 计划并由用户批准。
