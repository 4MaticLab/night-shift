# 美术方向

风格为 Literary Storybook Noir：深夜城市、雨雾、老电车、纸张与墨水、黄铜和暖色窗口。核心色为 Ink Black `#090D18`、Deep Navy `#0E1628`、Paper Beige `#E7DCC5`、Amber `#C59A5A`，关系线使用 Oxidized Copper `#698D89`，矛盾使用 Old Wine Red `#8B4F4C`。

主标题使用 Newsreader，正文使用 Manrope，档案编号使用等宽字体。视觉层级由核心城市插画、编辑蚀刻物证、圆形夜印、五张 3:2 城市明信片、五张 2:3 植物学版画、CSS 城市地图、纸张档案卡与克制动效构成。等待过程中，当前夜印由暗到亮逐步显影，夜生植物由底部从种核长到开花；清晨先展示昨夜地点与路线，再揭示时间成果，最后展示时长与物证；收藏页同时保留雾灯温室、旅程册、五枚夜印与八件物证。

所有尚未收集的视觉档案沿用夜印的“未点亮”规则：保留对应明信片、植物、口袋小物、章节夜印、城区和人物原图，以低亮度、低饱和度和低透明度显示轮廓，不再用钥匙、锁头或 `NIGHT`／`DRAWER CLOSED` 文字替代画面。暗图只预告媒介与构图，不显示名称、传闻或决定性事实；权限、设备连接和密文解锁等真实操作状态仍可使用锁形图标。

全局指针点击使用短促的琥珀与纸色火花作为操作回声；火花层不拦截交互、不改变布局，并在系统偏好减少动态效果时完全停用。

城市明信片使用同一套原创版画语法：暖纸底、深海军蓝与炭黑墨线、有限琥珀灯光、旧铜绿、雨雾和轻微印刷错位。每张画面必须让城市的制度或建筑表现出人格，但不出现可读文字、品牌、现成作品角色或参考作品的专有构图。具体提示词见 [[docs/art-prompts/city-postcards]]。

城市剪报册使用对齐的档案标题与牛皮纸信封网格：尚未来到的白昼保持封口和酒红编号蜡印，已经归档的答复以铜绿编号标记并露出开封折线。四封信共享相同尺寸和基线，不再使用与媒介无关的深蓝空状态卡；信封只表达归档状态，不暗示行动点、得分或完成压力。

睡隙回声簿沿用相邻城市值更簿的 1180 像素档案宽度、内边距和五夜节奏，以耳听图记、左对齐标题和连续卡片网格承接上下文。真实醒转使用铜绿纸边与回声旁注，完整无醒转使用克制黄铜边，尚未归来的夜晚降低对比度；三种状态保持相同卡片骨架，空白不是待补进度，也不应被排成脱离页面流的散落文本。

夜生植物采用无文字的虚构植物学标本：完整根系与成熟株形居中，章节物件只作为根部或种荚的形态回声；不同睡眠层级通过缩放、金边与说明文字表达，不生成“枯死”版本。具体提示词见 [[docs/art-prompts/night-greenhouse]]。

地下社团使用 1:1 椭圆档案纹章：单一强轮廓、暖纸底、煤烟黑墨、铜绿、旧酒红与极少金线，缩小到 140 像素仍能辨认。晨报桌面布局中，纹章纸面与右侧社团来函使用完全相同的宽高并从顶部对齐；方形源图以居中裁切填满纵向纸面，保留中央纹章主体，不再留下漂浮的小图或空白色块。窄屏堆叠时恢复完整 1:1 画面。纹章只通过物件关系表达社团规矩，不出现文字、字母、数字、王冠、盾徽或现成作品可识别符号；具体提示词见 [[docs/art-prompts/city-societies]]。

关键人物使用 4:5 编辑蚀刻档案肖像：半身居中、背景留白、琥珀侧光和可在 160 像素辨认的职业道具。人物气质必须克制、有人味、各自有所保留；不得借用现成作品的种族、服装符号、头像边框或标志性构图。具体提示词与源图映射见 [[docs/art-prompts/city-witness-portraits]]。

三个城区使用 3:2 横向编辑版画：以道路或旧轨形成前景引线，以制度建筑构成中景，以雨雾保留远景空白。灯港区用水岸、花市与维修门辨认，旧子午区用钟楼、层叠石阶与旅馆辨认，玻璃丘用坡地温室、档案建筑与信号台辨认；具体提示词见 [[docs/art-prompts/foglight-districts]]。

核心流程使用四张 2:1 横幅建立分幕：交接保留左侧深色文案区，夜行保留中央路线叠层区，归来让黎明暖纸天空承载报告标题，裁决用无人站台和等待归还的证据承载选择。四张图保持林渡造型与蚀刻媒介连续，但不让插画替代交互；具体提示词见 [[docs/art-prompts/four-act-headers]]。

品牌 Logo 使用无文字的弯月电车正面：弯月承担夜班信号，三格车窗与中央琥珀灯保持旧电车意象，并在 34–42 像素导航尺寸中保留清晰轮廓。中英文品牌名由 HTML 排版，不写入图像；文件与生成记录见 [[docs/art-prompts/night-shift-logo]]。

睡前桌另使用一张 4:5 林渡交接肖像，把横幅中的同一张脸、深蓝外套、灰蓝围巾、肩包、手套、笔记本与黄铜手电拉近到可辨认距离。图像保持无文字的暖纸蚀刻，姓名、方向、随身物与目的地由 HTML/CSS 组成“今晚交接单”；主标题始终按完整语义短句换行，不留下单字孤行，小宽屏收紧字号与左右栏比例，平板竖屏则把场景和计划改为纵向阅读；选择只改变灯光和排版状态，不生成换装或好感表情。具体提示词见 [[docs/art-prompts/lin-du-handoff-portrait]]。

首页采用“夜班事务所海报 + 一张主卷宗”的双焦点构图：左侧只承担品牌命题、核心循环和主操作，右侧以票据穿孔、细金线、圆形档案章和等宽状态组成当前案件主卡，其他卷宗降为紧凑入口。人物面部保持在卷宗上方的可见区域，深海军蓝遮罩从左向右减弱；不再用右下角第二张预告重复当前案件。移动端恢复单列阅读顺序，先理解命题和主操作，再滚动到案件主卡。

案件序章把每案已有的主视觉、关键证物和交接画面依次作为全幅背景，以深海军蓝渐隐、左侧细金线和档案编号统一成三幕。桌面保留右侧人物／场景焦点与左侧阅读面，手机改用上下渐隐，让标题、证词和主操作在同一视口完成；图片不承载可读文字，异象、证物与首夜目标始终由 HTML 排版。新案件可以复用本案已经过审的素材，但三幕都必须引用本案资产注册表中的完成品，不能借用其他案件画面或另起一套界面语言。

睡眠硬件使用四张 1:1 暖纸设备档案画面：戒指、手表、床垫感应带和枕头保持深蓝器物、黄铜测量弧、旧酒红定位点与少量铜绿传感光。画面不使用电商白底、厂商品牌或健康 App 图表；连接状态、权限和指标继续由响应式 HTML/CSS 承担。具体提示词与源图见 [[docs/art-prompts/sleep-hardware-dossiers]]。

《黎明前出炉的第十三个面包》保留全局深海军蓝、铜绿、旧纸与克制暖光，把电车票据换成面粉尘、旧搪瓷、公共热力管和黄铜持份环。构图反复出现“十二个有主单位围住一个开放空位”，但不要求生成图承担精确数数谜题；决定性数量与因果仍由证物文本表达。人物肖像保持编辑蚀刻距离，城区保持横向档案版画，植物与收藏沿用既有纸面媒介，因此切换案件时能明显换题材而不换产品。完整提示词组与 34 张运行时映射见 [[docs/art-prompts/thirteenth-loaf-visual-archive]]。

《千早诺亚的第十三次旅行》继续使用相同暖纸编辑蚀刻，把母题换成入境票、纸结、错位街图、铜绿镜片和十三扇分别开启的门。镜面只用双线错位与局部银灰表达，不使用霓虹故障或赛博朋克；千早诺亚以 20 世纪初日本游学生的旅行外套、车票与实际行动建立身份，不使用猎奇“东方少女”、祭司服或动漫造型。第四案的 34 张运行时映射与身份连续性见 [[docs/art-prompts/chihaya-noa-visual-archive]]。

参考 Fallen London 的文学密度与媒介气质，但不复制其角色、徽章、边框、地图构图或界面布局。原创边界与玩法合成原则见 [[docs/north-star]]。
