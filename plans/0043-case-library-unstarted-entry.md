# 0043 — 卷宗库未开封案件入口

- 状态：`completed`
- 优先级：P0
- 创建：2026-07-24
- 更新：2026-07-24
- 负责人：Codex
- 依赖：[[plans/0025-multi-campaign-runtime]]、[[plans/0039-default-case-home-art-pass]]
- 推进模式：`auto`

## 动机

玩家从已有进度的案件返回首页卷宗库，切换到尚未开封的案件后，主操作按钮虽然启用却无法进入序章。已有进度的案件仍能继续，因而表现为“只能玩当前案件”。

## 范围

- 修复卷宗库打开状态阻断未开封案件序章的问题。
- 覆盖“已有 CASE 002 → 返回卷宗库 → 切换 CASE 001 → 进入序章”的真实路径。
- 同步当前浏览器回归基线。

## 非目标

- 不重做首页案件卡片视觉或卷宗库信息架构。
- 不改变案件存档隔离、默认案件或序章内容。
- 不直接向 `main` 推送。

## 任务

- [x] 在本机浏览器复现并确认状态分支根因。
- [x] 修复启动未开封案件时的卷宗库状态。
- [x] 增加跨案件浏览器回归。
- [x] 完成浏览器实测、测试、lint、构建与文档校验。

## 验收标准

- 从已有进度案件返回卷宗库后，未开封案件的主 CTA 能立即进入该案序章。
- 启动目标案件不会覆盖来源案件进度。
- 全新首页、已有案件继续、沙盒案件入口不回归。

## 验证

- `npm test`
- `npm run lint`
- `npm run build`
- `npm run docs:check`
- `npm run test:e2e`
- 本机浏览器跨案件入口复核

最终结果：

- `npm test`：79/79 通过。
- `npm run lint`：通过。
- `npm run build`：Next.js/Vercel 生产构建通过。
- `npm run docs:check`：79 篇 Markdown 双链全部通过。
- `npm run test:e2e`：33/33 通过，新增跨案件卷宗库入口路径。
- 本机浏览器确认刷新可进入 CASE 001 序章；修复后自动化完整复现“CASE 002 已有进度 → 返回卷宗库 → CASE 001 未开封 → 进入序章”。

- 2026-07-24：范围属于仓库内、可回滚的现有功能修复，按 `auto` 计划进入施工。

- 2026-07-24：既有测试只覆盖全新首页切换，新增从已开始的第二案返回并启动未开封首案的端到端路径。
