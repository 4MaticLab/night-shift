# 当前质量基线

## 已验证能力

- 五夜确定性案件内容、12 条线索、8 件收藏品。
- 三种睡眠质量都推进主线，安稳睡眠提供更完整内容。
- 三件随身物为每夜提供不同环境回响，但不改变固定线索。
- 五枚夜印随完成章节积累并通过本地存档保留。
- 八件收藏品均使用独立的编辑蚀刻插画，不再以字符作为主要视觉。
- 首页、三幕开场、睡前交接、12 秒夜间模拟、晨报、案件板、收藏和三个结局。
- Zustand 浏览器本地存档、Demo 抽屉和 `Shift + D` 快捷键。
- 服务端可渲染产品标题与社交分享元数据。

## 验证命令

```bash
npm test
npm run lint
npm run build
npm run test:render
npm run docs:check
```

Playwright Happy Path 位于 `tests/e2e/night-shift.spec.ts`，覆盖开始案件、选择方向、模拟睡眠和查看首份晨报。

## 已知边界

- 当前主要体验集中在单一客户端页面，功能域尚未拆分。
- “真实模式”跨夜计时尚未形成与 Demo 模式同等完整的交互路径。
- 关系确认是快速演示交互，尚未实现真正的“两证物连线”推理约束。
- 浏览器端视觉回归、完整五夜 E2E 和移动端交互尚未纳入自动验证。

这些边界的候选改进见 [[plans/0003-mvp-quality-hardening]]。
