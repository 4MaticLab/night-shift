# 五夜海报进入指南与触发情况

本文说明五夜案件碎片海报从哪里进入、每个入口会打开什么、哪些操作会触发二维码或打印行为，以及该功能明确不会触发什么。海报是独立的宣传与印刷页面，不参与案件存档和五夜结算。

## 入口速查

| 入口 | 适用情况 | 打开结果 |
| --- | --- | --- |
| `/posters` | 设计检查、五款总览、一次导出完整系列 | 依次显示五张海报；打印时生成五个 A3 页面 |
| `/posters/1` | 第一日案件启封 | 只显示第一日海报；打印时生成一个 A3 页面 |
| `/posters/2` | 第二日林渡角色公开 | 只显示第二日海报；打印时生成一个 A3 页面 |
| `/posters/3` | 第三日米娜人物公开 | 只显示第三日海报；打印时生成一个 A3 页面 |
| `/posters/4` | 第四日城市档案公开 | 只显示第四日海报；打印时生成一个 A3 页面 |
| `/posters/5` | 第五日最后一班公开 | 只显示第五日海报；打印时生成一个 A3 页面 |
| 海报上的二维码 | 现场观众从纸面进入游戏 | 打开网站首页 `/`，并附带该海报对应的来源参数 |
| 工具栏“打开游戏” | 网页预览人员快速检查游戏入口 | 在新标签页打开网站首页 `/` |

访问独立海报时，日期必须是规范的 `1`、`2`、`3`、`4` 或 `5`。不存在的日期、前导零形式或其他字符串不会匹配海报，会进入站点的 404 页面。

## 用户进入步骤

### 从网页预览进入

1. 打开最终部署域名后的 `/posters`。
2. 在顶部工具栏选择“第 1 日”至“第 5 日”，或点击每张海报上方的“打开独立预览”。
3. 使用“海报总览”返回五款连续页面。
4. 使用“打开游戏”验证最终玩家入口。

总览适合设计审阅和整套输出；独立页面适合日更发布、单款补印、单页分享和现场大屏轮播。

### 从实体海报进入

1. 玩家使用系统相机或扫码工具扫描海报底部二维码。
2. 浏览器打开同一部署域名的网站首页，而不是海报预览页。
3. 首页 URL 携带打印渠道、五日系列和当日款式参数，便于区分线下来源。
4. 玩家按游戏首页正常流程进入案件；海报本身不代替序章，也不自动推进章节。

正式印刷前必须从最终线上域名打开海报并重新导出 PDF。二维码按照当前请求的域名生成；从本机开发地址导出的二维码会指向本机，不能用于现场成品。

## 页面触发条件

### 路由触发

- 请求 `/posters` 时，服务端读取五张统一内容数据并渲染总览。
- 请求 `/posters/{day}` 时，服务端把 `{day}` 转为数字并查找对应海报。
- 只有数字与原始路径字符串完全一致且处于 1–5 时才渲染；其他值触发 `notFound()`。
- 页面核心标题、文案、图像和二维码均由服务端输出，不依赖点击后才加载。

### 二维码生成触发

每次服务端渲染海报页面时，会根据请求头中的协议和域名生成二维码目标：

- 优先读取代理提供的 `x-forwarded-host` 与 `x-forwarded-proto`。
- 没有代理头时使用当前 `host`；本地主机默认使用 `http`，线上域名使用 `https`。
- 二维码固定进入 `/`，不会进入 `/posters`。
- 二维码使用高容错等级，冷白底与深蓝码点保持扫描对比度。

二维码附加以下来源参数：

- `utm_source=print-poster`
- `utm_medium=offline`
- `utm_campaign=five-night-case-fragments`
- `utm_content=day-01-case-file` 至对应每日标识

这些参数只描述入口来源，不解锁内容、不改变剧情，也不创建账号。

### 打印触发

- 点击工具栏“打印 / 导出 PDF”时，浏览器执行原生 `window.print()`。
- 用户也可以使用浏览器菜单或系统打印快捷键进入相同流程。
- 进入打印媒体后，页面应用 A3 竖版、零页边距和精确保色规则。
- 工具栏、总览说明、单页提示和预览标签在打印时隐藏。
- 总览中的前四张海报强制分页，第五张结束后不再生成额外空白页。
- 独立页面只保留当前一张海报。

浏览器不会自动弹出打印窗口；必须由用户主动点击或使用打印命令。

## 运营发布时间触发

当前代码没有按日期自动锁定或解锁海报。五日公开由现场运营人员控制发布时机：

| 运营节点 | 建议公开入口 | 现场动作 |
| --- | --- | --- |
| 第一天开场 | `/posters/1` | 张贴案件启封款，引导首次扫码 |
| 第二天角色时段 | `/posters/2` | 公开林渡交接与异步玩法 |
| 第三天人物讨论 | `/posters/3` | 公开米娜证词，引导讨论矛盾 |
| 第四天系统展示 | `/posters/4` | 公开城市档案与证词整理 |
| 第五天体验收束 | `/posters/5` | 公开最后决定，引导完成五夜 |

如果不希望观众提前看到后续海报，不应公开 `/posters` 总览地址；应只分享当天独立 URL，并在现场物料、社交媒体和大屏中人工控制发布时间。由于路由本身没有鉴权，知道后续 URL 的人仍可直接访问；这属于宣传发布策略，不是安全隔离。

## 明确不会触发的行为

打开、切换、打印或扫描海报都不会：

- 修改本地游戏存档、当前夜晚或案件进度。
- 自动开始睡眠、夜间结算或晨报。
- 解锁线索、藏品、人物、城区或结局。
- 请求健康数据、设备权限、钱包连接或登录。
- 自动记录个人身份；二维码只携带静态来源参数。
- 自动按真实日期发布或隐藏某一日海报。
- 因为睡眠时长、设备状态或玩家选择而改变海报内容。

## 故障判断

- **海报能打开但二维码指向本机**：PDF 从开发环境导出；改用最终部署域名重新导出。
- **独立日期返回 404**：确认路径使用 `/posters/1` 至 `/posters/5`，不要使用 `/posters/01`。
- **打印出现工具栏**：确认使用浏览器打印而不是网页截图，并等待样式完整加载。
- **总览多出空白页**：确认纸张选择 A3、边距为无、缩放为 100%，并使用 Chromium 内核浏览器复核。
- **二维码难以识别**：开启背景图形、不要裁切冷白安静区，并用真实纸样测试尺寸和反光。
- **后续日被提前看到**：不要向观众分享总览 URL；只发布当天独立入口。若需要真正的访问限制，必须另行实现服务端发布时间或鉴权，本功能目前不提供。

## 验收清单

- [ ] `/posters` 显示五张深蓝基调海报。
- [ ] `/posters/1` 至 `/posters/5` 分别显示唯一日次。
- [ ] `/posters/0`、`/posters/01`、`/posters/6` 和非数字路径返回 404。
- [ ] 最终域名导出的五个二维码都进入同一游戏首页，并具有不同的 `utm_content`。
- [ ] 点击打印后总览为五页、独立入口为一页，控制区不进入成品。
- [ ] 打开海报前后，游戏存档和案件进度保持不变。
- [ ] 运营人员明确采用人工日更，或另行实现真正的发布时间限制。
