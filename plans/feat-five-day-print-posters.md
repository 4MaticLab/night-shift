# 五日案件碎片印刷海报

- 状态：`completed`
- 优先级：P1
- 创建：2026-07-24
- 更新：2026-07-24
- 负责人：GitHub Copilot
- 分支：`feat/five-day-print-posters`
- 依赖：现有首案美术资产、二维码依赖 `qrcode`
- 推进模式：`auto`

## 动机

黑客松现场需要连续五天公开案件碎片、角色设计和玩家引导，并一次印刷 200 份。当前仓库有完整首案美术与文字，但缺少统一的海报系列、网页预览和打印版式。

## 范围

- 建立五张首案连续海报的数据结构与原创文案。
- 提供海报总览页和五个独立预览 URL。
- 提供 A3 竖版、可缩放至 A4 的浏览器打印样式和可扫描二维码。
- 编写海报结构、发行节奏、印刷规格和质量检查文档。
- 更新文档索引和稳定美术规范。

## 非目标

- 不生成新的位图资产，复用仓库中已审核的首案美术。
- 不公开案件最终真相、人物保留意见或完整解谜答案。
- 不接入印刷供应商、支付、批量下单或外部短链服务。
- 不修改游戏存档、主循环或案件规则。

## 验收标准

- `/posters` 可看到五张海报总览并进入每一张独立预览。
- `/posters/1` 至 `/posters/5` 均可打开，包含不同案件碎片、角色／世界观设计、用户引导和真实二维码。
- 浏览器打印总览时恰好输出五个 A3 竖版页面，控制按钮不会进入成品。
- 每张海报在不依赖 JavaScript 交互的情况下服务端渲染核心文案和图像。
- 海报不泄露完整真相，二维码指向带来源参数的游戏首页。
- 稳定文档说明版式结构、五日叙事、印刷规格和现场投放建议。

## 验证

- `npm test`：14 个测试文件、120 项测试通过。

- `npm run docs:check`：90 个 Markdown 文件全部通过。
- 浏览器检查 `/posters` 和 `/posters/1`–`/posters/5`：五张文案、主图、副图与二维码均正常加载。

- 打印媒体检查：总览包含五张海报，前四张 `break-after: page`、第五张 `auto`；A3 尺寸生效，工具栏和页面说明隐藏。
