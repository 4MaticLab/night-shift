# 雾灯夜兆牌桌

雾灯夜兆牌桌是收藏页中的每日文学仪式，对应 GitHub Issue #92。玩家每天为当前案件翻开一张原创塔罗画风卡牌，得到正位或逆位解读与一个反思问题。它不是奖励池、占卜承诺或案件提示系统，不会改变任何游戏成果。

## 入口与触发

1. 玩家开始任一案件后进入 `/game/collection`。
2. 在收藏档案分类中选择“夜兆牌桌”。桌面宽屏也可在收藏长卷中向下浏览到该区域。
3. 本地存档水合完成且当前案件今天尚未抽取时，“抽取今日夜兆”按钮可用。
4. 点击按钮立即写入今天的牌面、正逆位、案件 ID、本地日期与时间，然后播放一次翻牌动画。
5. 同一案件同一本地自然日再次访问、刷新或重启浏览器，只显示已保存结果，按钮保持禁用。
6. 本机时间跨过次日 00:00 后，页面自动开放新一天的抽取，不要求刷新。

日期使用设备本地的年、月、日，而不是 UTC 日期。切换案件后，每个案件拥有独立的当日结果和最近七次历史；它们共享同一浏览器的随机种子，但稳定哈希输入包含案件与日期，因此互不覆盖。

## 九张原创夜兆牌

牌组位于 `src/content/tarot.ts`，所有卡牌均有中英文标题、档案副题、正位解读、逆位解读和反思问题：

| 编号 | 牌名 | 叙事主题 | 复用资产 |
| --- | --- | --- | --- |
| 00 | 无主车票 | 允许问题存在，不预写终点 | 破损车票 |
| I | 夜班侦探 | 交接、行动与克制 | 林渡交接肖像 |
| II | 留信人 | 沉默、保护与追问 | 米娜肖像 |
| III | 玻璃丘 | 制度、分类与透明表象 | 玻璃丘城区版画 |
| IV | 错页保管人 | 临时保护与长期占有 | 奥林肖像 |
| V | 四十三日花 | 等待、周期与边界 | 四十三日植物版画 |
| VI | 被删路线 | 可复核痕迹与地图否认 | 档案温室明信片 |
| VII | 索引蛾 | 错误指向与隐藏模式 | 索引蛾翅片 |
| VIII | 末站灯 | 真相抵达后的归属选择 | 隐藏站台结局画面 |

牌名与解读只借用 Night Shift 自有世界观，不复制现实塔罗的完整大阿卡纳名称、编号体系、专有图像构图或第三方作品牌面。

## 选牌规则

首次抽取时，独立 Zustand 存档创建一个本机随机种子。选牌函数分别对以下字符串执行稳定哈希：

- 卡牌：`localSeed | campaignId | YYYY-MM-DD | card`
- 正逆位：`localSeed | campaignId | YYYY-MM-DD | orientation`

卡牌索引对九张牌取模，正逆位对二取模。结果不是安全随机数，也不用于奖励、竞争或投注；稳定种子的目的只是防止刷新重抽。同一天如果记录已经存在，store 直接返回原记录，不重新计算或覆盖时间。

## 本地存档

夜兆使用独立存档键 `night-shift-tarot-v1`，只保存：

- `localSeed`：当前浏览器第一次抽取时生成的非零 32 位整数。
- `records`：以 `campaignId|YYYY-MM-DD` 为键的牌面记录。

它不写入 `night-shift-save-v1` 游戏存档，不参与案件存档版本与迁移。清除该站点的浏览器数据会同时清除夜兆历史；不同设备、浏览器或隐私窗口不会同步。功能不请求账户、Cookie、后端、通知权限或网络随机服务。

## 产品护栏

抽取、正逆位和历史牌列都不会：

- 解锁、增加或替换线索与核心物证。
- 改变睡眠质量、植物、夜印、明信片或口袋小物。
- 改变社团关系、人物说法、密文、结局资格或结局。
- 提供稀有度、数值、货币、保底、十连抽、付费入口或链上领取。
- 声称预测现实未来、健康、财务、关系或医疗结果。

牌面只把玩家已经带来的问题换一种文学角度放回桌面。界面必须持续展示“不改变游戏成果”的说明。

## 视觉与无障碍

- 牌背使用深海军蓝、黄铜细线、同心圆与弯月夜兆，不依赖新位图。
- 牌面将既有审核资产放进 3:5 暖纸卡框，以编号、标题、正逆位标签和对角档案标建立统一语法。
- 逆位只旋转牌面插画，不倒置标题与解读，保证可读性。
- 翻牌只播放一次；系统偏好减少动态效果时由全局规则将动画压缩到近乎即时。
- 抽取按钮保留键盘焦点轮廓、禁用状态和可读标签；结果区使用 `aria-live`。
- 900 px 以下收藏页只显示当前分类；390 px 手机把牌面、按钮和解读改为单列，并把历史牌列改为两列。

## 验收清单

- [ ] 收藏分类显示五组档案，并能进入“夜兆牌桌”。
- [ ] 空状态显示牌背、每日限制、本地保存和无游戏影响说明。
- [ ] 首次点击后出现一张牌、正／逆位、解读和反思问题。
- [ ] 刷新后牌面与正逆位不变，抽取按钮仍禁用。
- [ ] 游戏 store 在抽取前后完全不变。
- [ ] 切换案件不会覆盖另一案件的当日牌面。
- [ ] 清除 `night-shift-tarot-v1` 后只清除夜兆，不清除案件进度。
- [ ] 桌面、390 × 844 手机和减少动态效果模式下均可阅读与操作。
