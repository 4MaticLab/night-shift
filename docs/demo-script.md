# 90 秒现场演示

1. 0–15 秒：主页说明“你睡着以后，他才开始工作”，点击“开始第一宗案件”。
2. 15–35 秒：三幕开场后选择“让纸张先开口”；方向卡会提示可能惊动“错页登记处”。再带上“黄铜侧照灯”，点击“今晚交给你了”。夜间会明确显示“纸张的证词”方向、旧票据工坊路线事件、逐渐显影的夜印和从纸底向上生长的票根灯蕨。
3. 35–55 秒：晨报先展示城市明信片与路线来信，再揭示完整票根灯蕨和“提前醒来也不会枯死”的成长说明，随后收到错页登记处致“待核旁注”的第一封来函。选择“让错字继续保护地址”，界面会把答复归档；不选择也可以继续。最后展示随身物回响、路线、侦探日志、旧车票与“七年旧纸 / 昨天日期”的矛盾。
4. 55–75 秒：用底部导航打开案件板，点击“四十三天”，让城市先辩称那只是“一位顾客长期迟到而形成的礼貌习惯”；再选择“未寄出的明信片”，建立连接并确认“米娜知道伊芙琳仍然活着”。若时间允许，拖动一张证物并刷新，展示调查桌会记住摆放。
5. 75–90 秒：按 Shift+D 打开 Demo，选择“跳到真结局条件”，完成第五夜并展示真结局。终函之后快速扫过“五夜归来总账”和实际物证，再点“重看档案／回到结案页”，说明旅程结果不是一次性统计画面，而是一份可回看的结案卷宗。

现场路径另有三条浏览器护栏：一条从新档连续完成五夜、过程中不使用章节跳转；一条验证五夜总账、八件物证与档案往返；另一条在 390 × 844 下真实操作首夜、收藏、档案、案件板和结案卷宗，并检查页面级横向溢出。演示时若临时改走这些页面，仍处在已验证路径内。

## 真实夜班补充演示

若需要说明长期玩法，在第二步切换到“今夜真实交接”，开始后刷新页面：夜班页面会按原交接时间恢复。点击“我醒了，拆开报告”后，晨报会展示实际记录时长；提前结束仍会获得主线线索。

若需要说明跨夜城市记忆，在 Demo 中跳到第三夜并完成“替307号房完成退房”：错页登记处的第三封来函会先引用上一封答复的余波，再提出新的问题。随后打开“收藏”，城市人情簿会显示两次默认答复、对应问函和即将进入后续来函的余波；页面不会显示声望分数。

若需要说明旅行式意外成果，完成任意一夜后在晨报停留“口袋里多出来的东西”：它明确不提供案件优势。再打开“收藏”的口袋抽屉，可以看到已归来的小物、当夜路线、随身物与林渡短笺；Demo 跳章会使用固定种子，因此每次演示保持一致。
