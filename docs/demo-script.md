# 90 秒现场演示

1. 0–15 秒：主页说明“你睡着以后，他才开始工作”。公开书架只展示持续更新的《零点四十三分的末班车》和标明“结构样板”的《黑水溪》；进入主案后落在雾灯城纪事地图，而不是案件倒数页。
2. 15–32 秒：地图左侧选择《末班车》第一段，在三个调查方向中安排一项 12 秒 Demo。交接后立即回到城市地图，指出卡片仍显示“夜班进行中”，地图与其他故事线没有被锁住。
3. 32–52 秒：用 Demo 连续归档前三段主线证物，使河下区从雾中显影。打开《潮汐不肯归档》，从“被刮掉的线路”或“箱子上的姓氏”进入，在夜渡码头安排“重抄最后一班名册”，再返回地图。
4. 52–72 秒：地图同时显示两条活动故事线。拆开《末班车》的晨报并归档固定线索；河下区仍保持自己的计时或待拆报告，证明主线与支线会话互不覆盖。等待时长只改变叙事层次，不改变证物和人物事实。
5. 72–90 秒：展示三组跨线连接：被刮线路 ↔ 夜渡名册、空白地图 ↔ 盐结门牌、账册黄铜扣 ↔ 原始工程总账。最后停在“继续填入新 storylet、地点和人物”的城市地图，说明每条线会按自身条件走到收束，版本更新不需要再增加 CASE 编号。

浏览器护栏覆盖公开两卡书架、桌面与 390 × 844 城市地图、主／支线并发夜班、河下区完整居民返程路径和《黑水溪》既有流程。旧五夜、雨中电台、好友线索与密文台不再有演示入口；带 `?legacy=1` 打开也仍进入城市纪事。

## 真实夜班补充演示

若需要说明长期玩法，在第二步切换到“今夜真实交接”：界面会按设备本地时间预告掌灯、夜半、末更或白昼小憩。开始后点击“我只是醒了一下”，睡隙纸条出现但夜班不会结束，同一夜按钮随即锁定；刷新页面，夜班会连同原交接时间、时辰和这条回声恢复。点击“我醒了，拆开报告”后，晨报展示实际记录时长、该时辰独有的场景以及睡隙短笺。提前结束仍会获得主线线索，时辰与醒转也不会改变睡眠评价。

若要说明早期开发的升级策略，可以预置旧 epoch 后刷新：应用只清空 Night Shift 进度并回到新书架，语言选择保持不变。该行为有单元与浏览器护栏，不需要现场手动清理整个 localStorage。
