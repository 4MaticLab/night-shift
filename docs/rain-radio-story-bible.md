# 故事圣经：只在雨中播出的电台

雾灯城九十七点三兆赫电台停播十二年后，只在雨水接通铁皮屋顶、排水管和旧民防铜线时重新发声。它读出的不是预言，而是比市政公告早一天送到印刷所的删改校样：规划部门先从地图和公告里删除三个旧街区，再把四十七户仍在居住的人写成空地。

播音员严洛没有失踪或死亡。她藏在废弃防空通信网里，和居民共同维护雨水中继，把门牌、呼吸和证词绕过普通电话线路送回广播塔。停电控制台上的余温、空白校样的压痕、沉默来电簿、编号钥匙与中继封条共同证明这是一套仍由活人维护的证言网络。

固定事实不可被动态叙事改变：所谓“明日新闻”来自提前取得的市政印版；街区在拆迁令发布前已被行政删除；四十七户居民仍然存在；严洛主动保存证词，但拒绝替居民决定何时、以何种身份公开。第五夜的冲突不是找出神秘播音员，而是公开全部声音、先保护说话者，还是把播音权交还给居民。

三种结局都承认调查事实，但承担不同代价。真结局“把话筒交还居民”要求玩家亲自取得全部线索、足够物证并完成三条核心推理；好友送达的线索可以帮助理解和连接，不能替代亲自完成调查。

林渡在本案仍负责夜间行动，玩家负责白天推理。共享的雾灯城社团、问函和纪念物可以回应玩家的调查姿态，但不得改写严洛、四十七户居民、市政删改顺序或结局资格。
