# 叙事、玩法与美术北极星

## 目标体验

玩家应该感到：雾灯城并不是一张等待被解谜的背景图，而是一座有偏见、有规矩、会记仇也会寄错信的城市；林渡不是玩家的遥控角色，而是一个会根据准备自行选择路线、在玩家离开后继续生活的人。

长期目标是把三类设计力量融合成原创体验：

1. **文学性地下都市**：借鉴 Fallen London 的文字密度、黑色幽默、地点人格和“每个选择都有余波”的叙事感觉。
2. **时间长出可见成果**：借鉴 Forest 把真实时间转化为可收藏、可回看的视觉痕迹。
3. **准备之后放手等待**：借鉴《旅行青蛙》由行前准备影响自主旅程、回程照片和纪念物的不确定期待。

参考来源：[Fallen London 官方介绍](https://www.failbettergames.com/games/fallen-london)、[Forest 官方介绍](https://www.forestapp.cc/en/)、[《旅かえる》官方介绍](https://hit-point.co.jp/games/tabikaeru/index.html)与[官方 FAQ](https://www.hit-point.co.jp/games/tabikaeru/faq/faq_en.html)。

## 可迁移原则

### 叙事

- 城市拥有自己的动词与习惯：吞掉地址、借走钟声、让路灯替人作证。
- 每个地点至少有一条公共传闻、一条私人规矩和一个不合时宜的小幽默。
- 选择文案不仅写“去哪里”，还写玩家愿意承担哪种代价或相信哪种解释。
- 日志保持第一人称克制；系统旁白可以更狡黠，但不能替玩家下结论。
- 线索必须回响：旧物第一次是物证，后来成为人物关系或道德选择。
- 城市来函必须允许玩家回应；后续文字引用具体答复，但不能把文学选择压缩成善恶值、好感条或最优解。

### 等待玩法

- 睡前准备包含**调查方向 + 一件随身物**。随身物不改变主线真相，但改变路线、旁观细节、回信语气或额外纪念物。
- 夜间等待必须有可见生长：路线逐段亮起，城市档案形成一枚“夜印”，完成的睡眠成为连续收藏，而不是分数。
- 不采用 Forest 的失败惩罚。提前醒来不让“树枯死”，而是生成一段更短、更奇异的城市回声。
- 保留《旅行青蛙》式不可控性：玩家做准备，林渡负责决定怎样使用；奖励不是精确兑换表。
- 回来时优先呈现“他去了哪里、看见什么、为什么带回这件东西”，再呈现时长摘要。

### 美术

- 从“整张电影插画”推进到“插画 + 雕版小像 + 档案物证 + 城市纹章”的混合系统。
- 深海军蓝和暖纸色保持温暖；增加烟煤黑、氧化铜绿、旧酒红和稀薄金线。
- 人物与地点采用编辑插画和蚀刻感边缘，UI 保持原创的轮班、车票、夜印和报告语言。
- 图像不得复制 Fallen London 的具体角色、徽章、地图构图、边框或界面布局；参考的是文学密度与媒介气质，不是 trade dress。

## 体验指标

- 玩家在交接前能说出“我今晚给了林渡什么，以及我希望它怎样影响旅程”。
- 晨报至少包含一处城市人格、一处准备物回响和一个明确的新问题。
- 五夜结束后，玩家拥有一组能复述旅程的夜印、路线和纪念物，而不是单一进度百分比。
- 新文本通过固定事实校验，不因风格升级改变案件真相。
