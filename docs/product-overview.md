# 产品概览

## 一句话定位

《夜班侦探 Night Shift》是一款与你轮班生活的异步侦探游戏：玩家白天分析线索并安排方向，睡着以后，侦探林渡替玩家进入城市调查。

核心情绪不是睡眠管理，而是：**我想早点睡，因为我想知道侦探今晚会发现什么。**

长期叙事、玩法与美术方向见 [[docs/north-star]]。

## 核心循环

```text
晨间报告 → 白天推理 → 选择方向与随身物 → 睡前交接
    ↑                                  ↓
获得线索、藏品与矛盾 ← 夜间城市调查 ← 玩家休息
```

每次睡眠都推进主线。睡眠较短时路线更短但仍有关键发现；稳定、充足的睡眠带来环境观察、支线信息和更多收藏，而不是简单分数。每夜三个调查方向会改变林渡先去哪里、沿途遇见哪条城市规矩以及寄回哪封路线来信，但不会改变必得线索；随身物则改变他注意到什么、谁愿意开口和明信片背面的附言。第一夜归来后的白天，门缝下还会出现三张稳定的城市告示：玩家可回应一张，也可全部收起；选择会在下一份晨报留下一句回声并进入剪报册，但没有行动点、奖励差或主线门槛。每个方向还会惊动错页登记处、失物领事馆或熄灯测绘社之一：社团跨夜记住玩家的做事方式，逐步更换称呼与来函礼数，并提出没有标准答案的小型问函。玩家可以选择两种答复，也可以不回信；同一社团下次会引用最近一次回答，但不存在公开声望点数、最优兑换路线或结局门槛。白天的案件板允许逐张阅读证物：城市会为每条事实提出一份体面的异议，林渡则留下克制的页边批注；玩家可以拖动整理，桌面摆放会随本地存档保留。等待过程中，一株章节专属的夜生植物会从种核、抽芽、展叶长到开花；提前醒来只得到较小但完整的植株，不存在枯死惩罚。真实夜班若只是短暂醒转，玩家可以留下每夜最多一次的“睡隙记录”再继续休息；城市会回寄一段声音、掠影和林渡短笺，同夜不可反复收集，也不改变任何评价或成果。每次完成的等待都会形成一枚“夜印”、一株温室标本，寄回一张城市明信片，并让口袋里多出一件无法精确指定的城市小物。纪念物由存档种子、方向、随身物与既有历史稳定决定，五夜不重复、刷新不重抽，也没有稀有度或案件优势。第二至第五夜还会让一位关键人物进入晨报；收藏页按相遇与现有证物逐层展开其档案，把城市的秘密重新落到有表情、也有保留的人身上。晨报与收藏页共同保存标本、路线、答复、城市人情、口袋小物、人物档案、睡隙回声和午后剪报。结案时，三个选择各有独立的林渡终函；页面会把当前存档真实走过的五夜路线、随身物、植物、纪念物与核心物证重新编成归来总账，并允许在不重置结局的情况下回看案件档案。

睡前交接发生在林渡的近距离桌前：玩家选定方向和随身物后，“今晚交接单”会把调查姿态、目的地和带走的东西写到他的肖像旁，明确这是把任务托付给一个会自行行动的人，而不是填写睡眠表单。交接提供两种节奏：Demo 把一夜压缩成 12 秒并固定为夜半时分，便于现场稳定理解循环；真实夜班从交接时刻开始记录，允许玩家锁屏或关闭页面，醒来再按实际时长拆开晨报。真实交接还会按设备本地时间落入掌灯、夜半、末更或白昼小憩；每夜四个时辰分别改变城市侧影、偶遇与林渡短笺，并进入晨报和城市值更簿，但不改变线索、收藏、植物、睡眠评价或结局资格。两种模式共享同一故事结算规则。

## 首个案件

《零点四十三分的末班车》包含五夜剧情、12 条核心线索、8 件收藏品与三个结局。详细固定事实见 [[docs/story-bible]]。

## 成功标准

- 15 秒内让新玩家理解“你睡着时侦探工作”。
- 60–90 秒内演示完整的交接、夜间调查、晨报和推理循环。
- 无后端、登录、环境变量或 API Key 时可完整体验。
- 睡眠差异增加叙事丰富度，不惩罚玩家。
- 美术统一为温暖故事书黑色电影，参见 [[docs/art-direction]]。

## 非目标

本项目不是医疗产品、睡眠评分工具、健康仪表盘、聊天机器人、签到积分应用或随机故事生成器。黑客松版本不建设登录、云存档、数据库、支付、多人协作或可穿戴设备接入。
