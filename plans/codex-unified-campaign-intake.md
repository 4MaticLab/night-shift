## 动机

Night Shift 已经拥有可切换案件的 `CampaignManifest`、按案隔离的存档和稳定的五夜状态机，但新增剧本仍可能在改编时把原作的行动结构直接搬进产品，造成“同一书架里像不同游戏”的断裂。接下来的三份剧本需要先经过同一套生命周期适配，再逐案施工；专属玩法只能丰富某一夜的调查表达，不能替换“你睡了，我干活”的核心关系。

视觉上以首案 [[docs/story-bible|《零点四十三分的末班车》]] 及 [[docs/art-direction]] 为规范实现：后续案件可以更换地点、物件、职业和局部纹样，但必须继续使用 Literary Storybook Noir 的媒介、色彩、排版、资产层级和克制动效，不能各自长成独立产品或另一套 UI。

本计划先冻结共同门槛并预留三个本机输入槽位。剧本一已经收到并完成首轮结构提取；本分支只交付剧本一和它需要的最小通用能力，剧本二、三将在剧本一试玩通过后分别建立新分支与临时计划，避免三宗大型案件堆进同一个 PR。

三份原始剧本是施工输入，不是稳定产品文档，也不应进入公开 Git 历史。本机已经预留以下文件；用户可把每份完整文本直接粘贴到对应文件的分隔线下：

1. `plans/.source-inputs/codex-unified-campaign-intake/script-01.md`
2. `plans/.source-inputs/codex-unified-campaign-intake/script-02.md`
3. `plans/.source-inputs/codex-unified-campaign-intake/script-03.md`

这些路径通过本仓库的本机 `.git/info/exclude` 排除跟踪。读取后，只把必要的原创改编、固定事实摘要、稳定 ID 和资产需求写入受版本控制的实现与文档；不得提交或在 PR 中转载大段原文。若任一文本的改编或发布权限不明确，只能先做内部结构分析，不能发布衍生内容。

## 两条不可妥协的门槛

### 1. 所有案件共享同一生命周期

每个案件都必须完整落在现有五夜循环中：

1. **案件书架／开案**：选择新案或恢复该案独立存档。
2. **白天研判**：阅读晨报与档案，在案件板整理证物、联合推理。
3. **睡前准备**：玩家选择调查方向与一件随身物，把方向交给林渡。
4. **夜间离线调查**：林渡在玩家离开后行动；Demo 和真实等待只改变时长表现与叙事丰富度。
5. **清晨归来**：先交代地点、路线与见闻，再揭示固定主线成果、回响和下一步。
6. **五夜裁决**：根据确定性线索、关系和既有规则进入三种裁决；睡眠质量不得锁主线或惩罚玩家。

新增案件不得：

- 新建平行状态机、独立首页、独立存档或绕开通用书架／交接／夜班／晨报／案件板／结案界面。
- 让玩家在夜间直接操控林渡，或用连续在线行动取代延迟探索。
- 通过睡眠时长、设备数据、随机生成或付费资源改变固定真相、主线线索、关系或结局资格。
- 为迁就原作而增加行动点、失败倒计时、刷取资源、跨夜惩罚或无法完成五夜主线的分支。
- 在通用页面中散落以 `campaignId` 判断的案件特例。

### 2. 所有案件共享首案美学语法

首案不是只供参考的 moodboard，而是资产与界面的验收基线。每案都要复用：

- Ink Black、Deep Navy、Paper Beige、Amber、Oxidized Copper 与 Old Wine Red 的全局色彩角色。
- Newsreader 标题、Manrope 正文、等宽档案编号的排版层级。
- 暖纸编辑蚀刻、深海军蓝墨线、有限琥珀灯光、雨雾、轻微印刷错位和克制金线。
- 四幕 2:1 横幅、人物 4:5 档案肖像、地区／明信片 3:2 版画、植物 2:3 标本、1:1 纹章／夜印、纸面证物和结案画面的既有资产分类。
- 首页、交接、夜行、归来、案件板和结案的共同构图层级；专属素材不得靠重做整套 UI 来成立。

题材变化只体现在案件自己的地点、职业、证物、植物形态、纹样与局部材质。每一资产组都要先写提示词和身份连续性约束，再生成候选、做运行时映射并在实际界面里验收；不得混用摄影、电商渲染、现代 SaaS 插画、不同画种的人物或可辨认的现成作品 trade dress。

## 案件内“特产组件”边界

允许每案拥有类似雨夜剧本 FM 调谐台的一个可选专属组件，但必须满足：

- 它是 manifest 声明、通用外壳承载的能力，不是页面对案件 ID 的硬编码。
- 它解释、核对或重组本案已写定的信息，不动态创造核心事实。
- 它不替换调查方向、交接、等待、晨报、联合推理或裁决。
- 它不阻塞每夜固定主线，不改变睡眠公平性，不把操作熟练度变成结局门槛。
- 没有专属组件的案件仍能完整运行；组件缺失或输入无效时安全回到通用流程。
- 桌面、iPad 竖屏与 390 × 844 手机均可键盘／触摸操作，不截断页面滚动或制造拖拽陷阱。

具体组件形态必须在读完对应剧本后提出，并记录“为什么它只能属于这个案子”以及“删掉后主循环为何仍成立”。默认每案至多一个主特产组件，避免功能堆叠。

## 三案待填设计卡

### 剧本 01

- 原文位置：`plans/.source-inputs/codex-unified-campaign-intake/script-01.md`
- 标题／来源：用户提供的原创策划稿《千早诺亚的第十三次伦敦旅行》；产品标题适配为《千早诺亚的第十三次旅行》。
- 改编与发布权限：用户明确交付本项目施工；原稿保持本机排除跟踪，公开仓库只提交 Night Shift 改编内容。
- 世界适配：把原稿伦敦地名映射为雾灯城的寄宿区、雾港入境厅、拱灯学会街和未成线，保留日本游学生、终灯会、返照镜与殖民式“东方收藏”批判；不把共享雾灯城系统强行搬到伦敦。
- 固定真相：
  - 千早诺亚连续十二次走完封印路线，每次重置都会产生一位真实生活过的诺亚；她们不是赝品或怪物。
  - 十二位旧诺亚被留在未成雾灯城，当前诺亚因千早家的返照训练保留部分跨版本记忆。
  - 终灯会把返照镜、铁路时刻表与城市地图组成仪式；仪式真正需要的是一名观察者宣布“谁才是原本的人”。
  - 十三份入境记录、照片与记忆互相矛盾，是因为来自不同现实版本，不是某一位诺亚说谎。
  - 案件最终问题不是辨认真伪，而是谁有权替十三个真实的人分配名字、存在与离开的资格。
- 五夜切分：
  1. **明日才抵达的委托人**：林渡分别查寄宿学校、雾港入境厅或停用站台，确认十二份入境记录与次日车票同时存在；诺亚主动调查事务所，不成为等待营救的目标。
  2. **两个都记得昨夜的人**：第十三号列车送来另一位诺亚；林渡沿纸结、裁纸刀与被改写地图证明现实发生过至少一次重置，不让玩家即时挑选“同行版本”。
  3. **拱灯学会的假东方**：调查终灯会公开外壳对被掠器物和诺亚身份的消费；固定取得返照镜碎片、仪式错译与地下站台图，路线只改变林渡如何保护她的主体性。
  4. **未成线的十二个地址**：林渡进入被删除的城市版本，确认十二位诺亚各自拥有连续经历，并查出观察者协议；“信任”通过证据和措辞表达，不写成好感值或战斗加成。
  5. **拒绝唯一原本**：十三位诺亚抵达镜前；玩家只在完整晨报与联合推理后决定公开、封存，或把命名与去留权还给十三人。
- 核心关系：
  - 十二份互斥入境记录 + 同源纸结路线 → 每次重置都留下了真实旅行者。
  - 返照镜碎片 + 未成线住址簿 → 旧诺亚仍拥有连续生活，不是当前诺亚的虚假倒影。
  - 观察者席记录 + 十三张独立签名车票 → 仪式依靠外部裁决抹除可能性，而非镜子自动选出真身。
- 三种裁决：
  - **公开十三份证词**：阻止终灯会私下裁决，但把十三人暴露在报纸、警方与猎奇目光下。
  - **封存返照档案**：先保护十三人的去向，却仍由事务所替她们保管名字与开启时机。
  - **把名字还给十三个人（真结局）**：拒绝指定唯一原本，让每位诺亚自行签署名字、去向与公开程度；终灯会失去观察者，返照镜不再能执行排除。
- 可选特产组件：使用现有“可选密文台”契约实现 **返照镜台**。新增通用、数据驱动的计数刻度模式，让玩家把十二份记录与一张明日票对齐到十三；其余两段核对纸结路线和观察者协议，最终按 `ARRIVALS → LIVES → RIGHT` 接回三份结论。它只重排已归档事实，不记录失败、不增加奖励、不决定结局。
- 视觉母题与首案语法映射：
  - 继续使用深海军蓝、暖纸、氧化铜绿、旧酒红、琥珀灯与编辑蚀刻；“镜面”用错位双线和局部银灰，不使用霓虹故障、赛博朋克或日式动漫语言。
  - 电车票据母题变为十三张入境票、纸结、铜镜裂纹与被改写站牌；人物仍是 4:5 暖纸档案肖像，场景仍是 3:2 城市版画。
  - 诺亚的日本身份通过合身的 20 世纪初游学服、旅行箱、纸结和实际文化知识表达，不生成拼贴祭司服、和服 cosplay 或猎奇“东方少女”造型；终灯会的错误服装只用文字批判，不作为主视觉。
- 预计资产矩阵：与第三案同量级的 34 张专属运行时资产——四幕横幅 4、证物 8、夜印 5、明信片 5、植物标本 5、人物肖像 4、地区版画 3；全部先进入独立提示词档案再映射 manifest。
- 风险与裁决：
  - 原稿三夜、实时同行、即时选择版本和长期搭档系统均不进入本案运行时；它们会破坏五夜异步生命周期或引入跨案状态。
  - 诺亚的主体性不能被压缩成好感条。路线选择只留下叙事回响；真结局仍由通用线索、收藏与联合推理门槛解锁。
  - “不要让两个诺亚同时活到天亮”保留为角色对仪式的误判与紧张钩子，不成为玩家必须杀死某人的目标。
  - 本案结案后可在文案中留下诺亚与事务所继续通信的可能，但不擅自把她写入其他已发布案件或建立永久伙伴加成。

## 非目标

- 不把原始剧本文本直接发布成可下载案件包。
- 不在收到剧本前承诺标题、案件编号、实现顺序、专属机制或资产数量。
- 不改变林渡负责夜间行动、玩家负责白天判断的角色关系。
- 不建立第二套战斗、跑团、即时探索或多人生存引擎。
- 不让 AI 生成器决定线索、人物关系、结局或因果。
- 不默认在本计划内完成三案英文翻译；中文案件完整接入后，翻译按 [[docs/translation-guide]] 一案一 PR 处理。
- 不为视觉差异重做全局导航、首屏、交接、晨报、案件板或档案信息架构。
- 不在没有来源和发布授权记录时把原作大段文本、专有图像或可识别 trade dress 纳入公开仓库。

- 剧本一从同一书架进入，并复用 `day → ready → night → morning → ending` 状态机、五夜节奏、林渡分工、案件板和结案流程。

- 新案实现不在通用页面散落案件 ID 分支；专属组件由通用契约声明，移除组件后案件仍可完整通关。
- 剧本一具有确定性固定事实、稳定 ID、完整引用、三种可解释裁决和可达的真结局条件。
- 剧本一与现有三案存档互不污染；切换、刷新、旧档迁移、好友线索和非法跨案输入均有自动测试。
- 剧本一运行时资产覆盖既有分类并通过实际页面验收；颜色、排版、媒介、构图和动效与首案一致，题材差异不演变为风格漂移。
