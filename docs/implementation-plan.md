# Night Shift 实施计划

## 交付目标

做出一条可在 90 秒内演示、也可完整玩完五夜的本地优先游戏循环。固定剧情事实，睡眠只改变调查丰富度，不决定成败。

## 阶段

- [x] Phase 1 — 基础工程：Next/React/TypeScript/Tailwind、字体、主题、Zustand 本地存档。
- [x] Phase 2 — 内容系统：五夜章节、12 条线索、8 件藏品、Zod 内容校验、夜间结算与单元测试。
- [x] Phase 3 — 核心循环：首页、三幕开场、睡前交接、12 秒夜间模拟、晨报与章节推进。
- [x] Phase 4 — 推理与收藏：可拖拽缩放案件板、三条核心关系、双层物品说明、档案页。
- [x] Phase 5 — 视觉与动效：故事书黑色电影主视觉、雨夜、纸张、地图、路线、晨曦与响应式布局。
- [x] Phase 6 — 结局与演示：三个结局、真结局条件、Demo 抽屉、Shift+D、E2E Happy Path。
- [x] Phase 7 — 发布：构建通过后保存版本并部署。

## 取舍

黑客松版本用单页面状态机承载所有“页面”，减少切页等待并保证现场演示稳定；存档保存在设备浏览器中，无后端或 API Key 依赖。
