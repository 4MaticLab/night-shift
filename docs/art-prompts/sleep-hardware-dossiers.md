# 睡眠硬件档案画面

## 共用媒介

四张设备画面使用 1:1 暖纸档案版画：深海军蓝器物、黄铜测量弧、少量旧酒红定位记号和铜绿传感点，以铜版蚀刻与石墨排线连接 1920 年代侦探卷宗和当代睡眠硬件。图像不出现人物、手、品牌、文字、数字或可操作 UI；名称、权限和连接状态全部由 HTML/CSS 呈现。

## 设备差异

- 睡眠戒：突出内圈传感器切面、城市轮廓和细金线脉搏。
- 睡眠表：突出深蓝表带、黄铜表圈、空白月影表面和底部传感器。
- 床垫感应带：突出织物压力波纹、卷起的感应带、小型传感模块和雨窗。
- 智能枕：突出深蓝亚麻、同心呼吸缝线、可拆传感扣和月夜窗景。
