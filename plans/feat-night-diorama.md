# 夜行立体纸剧场（2.5D 夜行图景试点）

- 状态：`completed`
- 优先级：P2
- 创建：2026-07-24
- 更新：2026-07-25
- 负责人：Qoder
- 分支：`feat/night-diorama`
- 依赖：无
- 推进模式：`auto`

## 动机

用户希望探索为产品引入 3D 要素。经讨论确定方向为"纸剧场／立体纸雕"式 2.5D：不引入真实感 3D，而是把既有版画美术按纵深分层，用视差、雾与灯火放大 Literary Storybook Noir 的媒介气质。首个试点选在夜行等待界面——"时间长出可见成果"的核心情绪载体。先在开发服务器联合调试，美学验收通过前不提 PR。

## 范围

- 新增 `src/components/game/night-diorama.tsx`：夜班阶段的分层 SVG 纸剧场。天空与月色、远景天际线、按路线变体变化的中景（灯港／花市／高地）、两层漂移雾带、沿路线前进的灯火与途经点亮的窗灯、前景栏杆与灯柱。
- `app/globals.css`：diorama 样式、preserve-3d 视差层、雾与灯火动效、响应式与 reduced-motion 回退，全部使用既有色板变量。
- `src/components/game/night-cycle.tsx`：仅 `NightRun` 一处用 `NightDiorama` 替换 `CityRoute`，进度、路线节点、地图变体与城市时辰作为 props 传入。

## 非目标

- 不引入 three.js、react-three-fiber、WebGL 或任何新依赖。
- 不改变夜间结算、存档结构、晨报内容与任何结局规则；晨报的 compact `CityRoute` 保持原样。
- 不做案件专属场景（四案共用同一套雾灯城天际线，仅按路线变体区分中景）。
- 不创建 PR、不提交合并；仅本地分支试点。

## 验收标准

- 夜行界面呈现克制纵深：远／中／近三层随指针产生小幅视差；雾带漂移；灯火沿路线随进度前进，途经窗户逐一点亮，站点到达后亮起。
- 色彩严格取自既有色板（--ink / --navy / --night / --slate / --amber / --teal / --red / --paper），无新品牌色。
- 场景状态是 progress 的纯函数，刷新／重开后与夜班进度一致，不依赖后台定时器。
- `prefers-reduced-motion` 下无视差、无动效，场景静态完整可读；粗指针设备不启用视差。
- 无新依赖；lint 与单元测试通过。

## 验证

- `npm run lint`、`npm test`。
- `npm run dev` 后浏览器驱动完整交接流程进入 demo 夜班，在多个进度点截图检查美学对齐与三种降级状态。

- 2026-07-24：联合评审后用户认可整体纵深，要求优化发光路线本体。经商议仅采纳「分层发光描边、保持克制」方案：已走路段改为三层叠加描边（6px/.14 + 3.2px/.3 + 1.6px 核心），替代原单色描边 + drop-shadow；平滑弯道、彗星尾迹、窗灯共振三项暂缓。
- 2026-07-24：环境教训——Turbopack 开发服务器多次出现 globals.css 变更不再触发重编译（持久缓存投毒），表现为新类名未注入导致 SVG path 回落到默认黑色填充。可靠恢复手段：删 `.next` 后重启 dev server，并以 chunk 内容探针确认后再截图。
- 2026-07-24：联合评审第二轮——用户指出发光路线图本身「有点怪」，提出第一人称游荡雾都的设想。经商议采纳「推车穿行」重构：删除路线图层与行进灯，相机随进度横向推进；场景改为四条等差视差卷轴（远 1860／中 3000／前景 3600 世界单位），中景窗灯在相机经过后点亮，前景灯柱掠过画面时增强光晕；四站点改为路边灯柱站牌（ahead/near/passed 三态），到达即亮；月亮随进度左移下沉，黎明前没入屋顶线。旧路线版（含分层发光描边）随之废弃。
- 2026-07-24：修复重写后两处回归：（1）天空 SVG 中月亮与星星不可见——静态 SVG 在不透明绝对定位 `.diorama-sky` 之下绘制（CSS 绘制次序：定位元素覆盖非定位元素），`.diorama-svg` 加 `position: relative` 修复；（2）站牌标签仍被右下生长面板裁切——站牌过中线后标签翻到杆左侧（flip），进出画面边缘时标签隐入雾中（shrouded，screenX > 0.84 / < 0.04）。
- 2026-07-24：终验——lint 通过、vitest 100/100；重截 6 组状态确认：月亮与星星可见且随进度移动、站牌三态与翻页标签无裁切、移动端底部居中面板不遮标签、reduced-motion 静态完整。
