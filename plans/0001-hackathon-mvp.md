## 动机

在无后端、无 API Key、无可穿戴设备的条件下，交付可直接部署和现场演示的《夜班侦探》首个完整版本。

## 范围

- 五夜确定性案件内容与本地存档。
- 首页、交接、夜间、晨报、案件板、收藏与结局。
- Cozy Storybook Noir 视觉和 90 秒 Demo Mode。
- 单元测试、服务端渲染检查、构建与私密发布。

## 非目标

- 登录、云同步、数据库、多人协作、真实硬件与医疗睡眠算法。

## 任务

- [x] 基础工程与本地存档。
- [x] 五夜内容、schema 和夜间结算。
- [x] 核心交接与晨报循环。
- [x] 案件板、收藏与档案。
- [x] 视觉、动效与响应式界面。
- [x] 三个结局与 Demo Mode。
- [x] 测试、构建并发布。

## 验收标准

- 无环境变量时可体验完整主循环。
- 三种睡眠质量都能推进故事。
- 评委可在 90 秒内看到交接、夜间、晨报、推理与结局。

## 验证

- `npm test`
- `npm run lint`
- `npm run build`
- `node --test tests/rendered-html.test.mjs`
- 已发布首个私密版本。
