## 动机

合并远端沙盒与睡眠硬件功能后，案件板组件仍按左画布、右推理栏组织，但最终双栏 CSS 在冲突解决时丢失，旧的绝对定位重新生效。实际页面因此把右栏悬浮在画布上方，匹配区和档案被裁切，并出现需要横向拖动的滚动条。用户要求在独立协作分支修复并提交 PR。

## 范围

- 恢复桌面端左侧画布、右侧普通内容框的真实双栏。
- 保证右栏、匹配槽、档案和核心论断完整适配列宽，不产生内部横向滚动。
- 在窄屏和手机端改为自然单列，画布之后完整显示推理、档案与核心论断。
- 增加线索索引，以符合档案美学的颜色、线头和纸框区分未结关系、当前候选与已选 A／B。
- 修正合并后重复的计划编号并同步稳定文档。
- 在独立分支验证、提交、推送并创建草稿 PR。

## 非目标

- 不修改证物内容、配对答案或核心论断规则。
- 不改动黑水溪沙盒、睡眠硬件桥接或其他案件页面。
- 不发布生产部署。

- [x] 修复窄屏／手机布局与横向溢出。
- [x] 更新自动化、计划编号和稳定文档。

- [x] 增加未结线索索引、候选色彩提示和高对比选中态。
- [ ] 提交协作分支并创建草稿 PR。

## 验收标准

- 1440 × 900 下画布只占左列，右栏是同级普通框而非绝对定位浮层。
- 右栏 `scrollWidth` 不大于 `clientWidth`，A／B 线索、核对按钮、档案与核心论断均完整显示。
- 页面不出现案件板导致的横向滚动条。
- 鼠标停在画布上滚动时页面纵向位移且 React Flow 缩放值保持不变。
- 画布背景拖拽、双击和捏合不改变视口；左侧缩放键仍可改变缩放值。
- 默认线索按总数生成最多四列的居中网格，“恢复摆放”回到同一布局。
- 线索索引只统计双方均已解锁且尚未确认的关系；普通未结关系使用氧化铜绿线头，当前候选变亮，已选 A／B 使用暖金纸框与圆形编号；纸卡不显示“可核对”文字标签，辅助技术仍可读取状态。
- 900 px 窄桌面仍保持左画布、右侧联合推理／当前线索档案双栏；仅手机宽度改为上下文档流。
- 390 × 844 下按画布、匹配、档案、核心论断自然排列，底部导航不遮挡最后内容。
- 既有拖动、匹配、分享和双案件主路径保持通过。
