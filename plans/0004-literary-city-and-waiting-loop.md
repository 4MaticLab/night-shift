## 动机

当前版本已经有完整故事骨架和统一夜色，但文本仍偏功能性报告，玩家对“睡前准备”的投入也只有调查方向；收藏页使用符号占位，等待结束后缺少能长期积累的个人旅程痕迹。新的北极星见 [[docs/north-star]]。

## 范围

- 建立原创的文学性城市叙事语法与可复用文案结构。
- 增加随身物准备，让同一主线产生不同环境回响。
- 增加“夜印”收藏，把等待时长变为可见的旅程记录。
- 用编辑插画与档案物证资产替换最明显的符号占位。
- 逐夜提升日志、地点传闻、选择和晨报的文学密度。
- 保持固定真相、无惩罚睡眠与 local-first。

## 非目标

- 不复制 Fallen London 的专有角色、地点、文案、徽章、地图或界面布局。
- 不照搬 Forest 的枯树惩罚，也不把睡眠变成绩效分数。
- 不让准备物改变主线线索是否存在或结局真相。
- 本计划不新增第二宗案件。

## 验收标准

- 玩家每夜可选择一件随身物，晨报明确回收其叙事影响。
- 完成睡眠后获得对应夜印，刷新后仍保留。
- 收藏页不再以抽象字符作为已解锁物品的主要视觉。
- 五夜日志有一致的城市人格、克制幽默与意象回响，同时不改变 12 条固定线索。
- 现有 Demo 主路径保持可用。

## 验证

- `npm test`
- `npm run lint`
- `npm run build`
- `npm run docs:check`
- 检查三种随身物在同一章节产生不同但不改主线的回响。
