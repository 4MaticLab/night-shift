# 全局背景音乐

全局背景音乐对应 GitHub Issue #84，为案件库、案件序章、游戏页面和海报预览提供同一条循环环境音乐。当前“C 小调夜曲”由项目所有者提供，已作为 48 kHz MP3 接入；代码不会下载第三方占位音乐。

## 音频文件契约

当前 MP3 位于：

`public/audio/c-minor-nocturne.mp3`

浏览器访问路径固定为 `/audio/c-minor-nocturne.mp3`。以后用同名文件替换时不需要修改组件或配置。素材交付说明也保存在 `public/audio/README.md`。

建议使用 44.1 kHz 或 48 kHz 立体声 MP3，首尾可无缝循环，不要保留过长静音；运行时音量固定为 `0.22`。提交前应确认录音、演奏与发行授权，并在非公开素材记录中保存来源和许可证。不得将来源不明的商业录音作为临时占位提交。

## 进入与自动播放

`BackgroundMusic` 挂载在根布局，整个站点只创建一个 `<audio>`：

1. 新访客默认开启背景音乐。
2. 根布局水合后立即以有声音、低音量方式调用 `play()`。
3. 如果浏览器允许自动播放，音乐立即开始并循环。
4. 如果浏览器以 `NotAllowedError` 拒绝，控制器显示“等待首次交互”；下一次指针或键盘交互会在可信交互回调中重试。
5. 如果 MP3 尚未上传或格式不可用，页面照常运行，图标降低对比度；不弹出提示框。

浏览器禁止有声自动播放是用户代理策略，网站不能可靠绕过。实现不会先静音播放再偷偷恢复，也不会伪装已经播放。Safari、Chrome、Edge、Firefox 和移动浏览器最终行为取决于用户既有媒体授权、节能模式和站点设置。

## 右上角控制器

音乐按钮固定在页面右上角，触控区域为 44 × 44 px，位于加载幕之上，并在所有站内页面保持挂载：

- 播放时只显示音量图标；关闭时只显示静音图标。
- 图标没有圆形外框、底色、三竖杠电平动画、常驻文字、悬停文字或提示方框。
- 点击关闭后立即暂停，并写入 `night-shift-bgm-enabled-v1=false`。
- 关闭状态刷新或重新进入仍保持关闭，不再自动调用播放。
- 再次点击会在该次可信交互中立即尝试恢复，并保存 `true`。
- 打印媒体完全隐藏按钮，不进入海报或 PDF。

存档只保存布尔偏好，不保存播放进度、设备信息、访问时间或收听历史。它独立于 `night-shift-save-v1`，不会随案件重置而清除。

## 生命周期

- `loop` 始终开启，曲目结束后从头继续。
- 根布局不随 App Router 站内导航卸载，因此案件库、序章和游戏页切换不会重新开始曲目。
- 标签页进入后台时主动暂停；恢复可见且偏好仍开启时继续尝试播放，减少后台耗电和意外出声。
- 页面卸载时由浏览器释放音频，不建立 Service Worker、Media Session 或后台播放能力。
- 音乐图标没有播放动画；系统偏好减少动态效果不会改变音乐本身，用户可随时使用按钮关闭。

## 缺失与故障状态

### 曲目待上传

仓库没有 `public/audio/c-minor-nocturne.mp3` 时，音频元素会进入 `missing` 状态。按钮仍可操作并降低对比度，页面不显示文字提示、不弹窗、不阻断加载。上传文件后重新加载页面即可启用。

### 等待首次交互

浏览器拒绝首次 `play()` 时进入 `blocked`。玩家点击页面任意位置或按键后重试；如果玩家直接点击音乐按钮，则这次操作视为关闭，不会继续播放。

### 暂时无法播放

网络中断、解码失败或其他媒体错误进入 `error`。界面不循环重试；玩家可以关闭后再开启，或修复资源后刷新。任何音乐失败都不得影响游戏路由、存档或交互。

## 产品与隐私边界

背景音乐不会：

- 读取、上传或推断玩家的音乐偏好。
- 写入案件、睡眠、硬件、钱包或塔罗存档。
- 改变线索、章节、结局、等待时长或奖励。
- 连接 Spotify、Apple Music 或其他第三方服务。
- 请求麦克风、通知、媒体库或后台播放权限。

## 验收清单

- [ ] 最终授权 MP3 位于 `public/audio/c-minor-nocturne.mp3`，可直接访问并无缝循环。
- [ ] 新浏览器立即调用一次有声播放；允许时开始，禁止时显示等待交互并在首次交互后恢复。
- [ ] 全站始终只有一个音频元素和一个右上角控制按钮。
- [ ] 案件库、序章、五个游戏页和海报页均可看到按钮，且站内导航不重置曲目。
- [ ] 关闭后刷新保持关闭；重新开启可立即播放。
- [ ] 后台标签页暂停，恢复可见后继续。
- [ ] 缺少 MP3 时页面不报错阻断，图标仅降低对比度且不出现提示方框。
- [ ] 音乐控件只有音量／静音图标，没有圆形外框、三竖杠、`title` 或可见提示文本。
- [ ] 390 × 844、键盘焦点、加载幕、游戏顶栏和海报打印均无重叠问题。
- [ ] 音频许可证、创作者署名与最终文件来源已经由项目所有者确认。
