# 当前质量基线

## 已验证能力

- 五夜确定性案件内容、12 条线索、8 件收藏品。
- 三种睡眠质量都推进主线，安稳睡眠提供更完整内容。
- 三件随身物为每夜提供不同环境回响，但不改变固定线索。
- 五枚夜印随完成章节积累并通过本地存档保留。
- 八件收藏品均使用独立的编辑蚀刻插画，不再以字符作为主要视觉。
- 首页、三幕开场、睡前交接、12 秒夜间模拟、可恢复的真实夜班、晨报、案件板、收藏和三个结局。
- Zustand 浏览器本地存档与 v2 迁移、Demo 抽屉和 `Shift + D` 快捷键。
- 真实夜班以持久化开始时间结算；关闭页面再返回仍能恢复进度，晨报会显示实际时长与派生质量。
- 服务端可渲染产品标题与社交分享元数据。

## 验证命令

```bash
npm test
npm run lint
npm run build
npm run test:render
npm run docs:check
```

Playwright Happy Path 位于 `tests/e2e/night-shift.spec.ts`：一条覆盖开始案件、选择方向、模拟睡眠和查看首份晨报；另一条覆盖真实交接、刷新恢复与醒来结算。测试使用本机 Chrome channel，避免依赖额外下载的 Playwright 浏览器。

## 已知边界

- 当前主要体验集中在单一客户端页面，功能域尚未拆分。
- 关系确认是快速演示交互，尚未实现真正的“两证物连线”推理约束。
- 浏览器端视觉回归、完整五夜 E2E 和移动端交互尚未纳入自动验证。
- 直接运行原生 `tsc --noEmit` 会缺少 Cloudflare Worker 全局类型；项目正式的 Vinext 生产构建不受影响。

这些边界的候选改进见 [[plans/0003-mvp-quality-hardening]]。
