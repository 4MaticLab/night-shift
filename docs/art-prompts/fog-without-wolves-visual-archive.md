# 《雾中无狼》视觉档案

CASE 005 的运行时视觉必须以首案现有成品为直接媒介参考，而不是重新解释“维多利亚怪奇”。核心参考为首案交接横幅、林渡档案肖像、旧子午区版画、夜印、植物标本和物证纸面：暖纸纤维、深海军蓝墨层、烟煤线刻、克制琥珀灯光、氧化铜绿、旧酒红与轻微印刷错位。

## 共用提示词

> Use case: illustration-story. Asset type: Night Shift campaign archive art. Original Night Shift literary storybook noir illustration, mature editorial gouache and dense dry-brush etching on aged paper, deep navy and charcoal shadows, oxidized copper patina, restrained amber lamplight, old wine-red accents, quiet rainy Victorian underground municipal city, tactile evidence archive, humane asynchronous investigation, subtle print misregistration. Match the supplied Night Shift reference only in medium, palette, finish, visual density, and archival restraint; create an original composition and original people. No readable text, letters, numbers, logo, watermark, photorealism, glossy 3D, neon cyberpunk, anime, gothic fashion editorial, romanticized killer poster, gore, literal wolves, tentacles, monster face, or existing franchise characters.

钟后聆听者始终通过负空间表现：错位的两道影子、声音波纹之间的空隙、没有钟舌的钟、先出现的回声和无法对齐的钟盘。不要为它生成固定身体。

## 人物连续性

- **林渡**：沿用首案同一名东亚男性侦探，约三十岁，短黑发、深蓝长外套、灰蓝围巾、棕色肩包、黄铜手电与黑手套。第五案横幅不得换脸、换年代或变成战斗英雄。
- **拉普拉斯**：约二十五岁的大陆女性，浅色凌乱长发，深蓝旅行外套，两只不成对的皮手套，神情危险而清醒；不做疯癫凝视、性感杀手或狼女。
- **特蕾莎·维尔**：约二十六岁，深色头发整齐束起，夜间货运调度员的克制深蓝制服，手杖与黄铜调度夹；平静是主动选择，不是冰冷反派。
- **艾达·莫恩**：中年剧院声学技师，卷起袖口，携蜡筒、音叉与旧工具，警惕但不神秘化。
- **费利克斯·罗**：消瘦的暮钟馆残党，旧礼服与白粉笔尘，普通人的偏执，不画成超自然教皇。

## 生成与验收

- 使用 Codex 内置图像生成能力；项目最终只保存筛选、裁切并压缩后的 WebP。
- 每一张资产单独生成，不用拼贴切图代替独立构图。
- 横幅必须在桌面与手机裁切下保留人物或制度焦点；人物面部不得被文案遮罩吞没。
- 肖像人物必须成年、主体完整、没有美化暴力或暧昧制服化。
- 精确时间、两份证词和推论关系由 manifest 文本表达，图像不承担可读文字或精确数数。
