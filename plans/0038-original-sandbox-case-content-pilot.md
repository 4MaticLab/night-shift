## 动机

当前三案的内容密度并不均衡。首案拥有五夜、12 条线索、15 条方向与最完整的插画资产，但调查顺序固定；第二案同样是五夜结构，人物档案仍为空；《黑水溪》只有 CSS 档案地图，却用 2 个入口、9 个地点、30 个行动、20 条证物、6 份手札、11 件物品、12 名人物、8 级污染与 5 个结局形成了目前最强的自由调查感。

本计划不继续扩写受授权约束的《黑水溪》，而是把它最有效的结构原则转化为 Night Shift 原创内容：双入口、非线性地点网、可追踪的传播链、人物状态、冗余线索和带明确代价的多种收场。题材、人物、地点、因果、美术与文案保持原创，延续雾灯城“制度会撒谎、建筑会作证”的语言。

## 案件提案

暂定案名为《潮汐不肯归档》（The Tide Refused to Be Filed），作为 `case-004`、`sandbox-expedition` 案件。

雾灯城河下区有一排街屋，每逢退潮会重新露出四十三分钟。市政水务处声称那里从未有人居住；夜渡船却持续收到寄给失踪住户的返程票。玩家从两个入口进入同一事实网络：

- **市政打捞书记员**：奉命找回一册能证明堤坝工程合规的账簿，拥有档案与工程入口。
- **夜渡船失踪者家属**：寻找被城市从户籍中抹去的亲人，拥有口述史与居民信任。

固定真相围绕一次被制度掩盖的强制泄洪、盐蚀档案和仍在重复最后一夜的街区展开。危险来自“回潮”逐步让调查者的姓名与归处变得不稳定，而不是复制《黑水溪》的溪水污染、母神、农场、威士忌或身体异变。

## 固定真相

以下因果是故事圣经的初始冻结项，后续写作不得用随机或生成文本改变：

- 河下区真实存在过，住户并非自然搬离；市政水务委员会为保护上游新城区，在暴雨夜主动打开泄洪闸。
- 委员会把遇难与失踪住户从户籍、赔偿名册和城市地图中一并删除，以便让工程在档案上变成“无人区例行排水”。
- 盐蚀档案室保存了被删除姓名的压印底版。退潮时，底版会让街道、门牌与住户最后四十三分钟的行动短暂重现。
- 夜渡船不是幽灵船；船夫和幸存家属一直在用返程票、钥匙与口述记录维持姓名和地点之间的联系。
- “回潮”不是疾病或身体污染，而是档案层面的身份错位：调查者越频繁替无名街区作证，城市的现行记录越难确认其姓名、地址与职务。
- 只关闭水闸不能归还姓名，只公开名单也不能立刻救出仍困在重复夜晚中的住户。来源、传播方式与受害者选择必须分别处理。

## 内容矩阵

| 地点 | 主要功能 | 行动数 | 关键产出 |
|---|---|---:|---|
| 水务委员会临时卷宗室 | 官方入口、工程谎言、初始分歧 | 3 | 修订过的泄洪令、赔偿空白页、委员会通行章 |
| 夜渡码头 | 家属入口、口述史、返程仪式 | 3 | 夜渡名册、返程票、船夫证词 |
| 第七泄洪闸 | 机械因果、风险升级、闸门选择 | 3 | 反向潮位尺、应急开闸记录、闸门钥匙 |
| 盐蚀档案馆 | 被删除姓名、手札、制度责任 | 3 | 盐版姓名、租住账、档案员旁注 |
| 无针钟棚 | 四十三分钟循环、时间证据 | 3 | 警报蜡筒、停摆钟芯、最后广播时刻 |
| 河下街屋 | 人物状态、钥匙与家庭选择 | 4 | 门牌拓片、住户证词、儿童路线图、幸存者去向 |
| 低潮记录室 | 真相汇合、回潮源头、终局行动 | 3 | 原始工程账簿、完整遇难名单、重绘河下区的母版 |

总量固定为 7 个地点、22 个行动。每个地点至少包含一个低暴露调查和一个会改变警觉、回潮或人物状态的行动；终局地点不得在单一路径后直接显影。

### 证物网络

16 条证物分为四组，每项核心事实至少由不同组的两条证物交叉确认：

| 证物组 | 证物 | 能证明什么 |
|---|---|---|
| 被删街区 | 空白赔偿页、盐版姓名、租住账、门牌拓片 | 河下区有人居住，删除发生在灾后而非灾前 |
| 工程责任 | 修订泄洪令、反向潮位尺、应急开闸记录、原始工程账簿 | 泄洪是有签字、有预警的主动决定 |
| 最后一夜 | 夜渡名册、警报蜡筒、停摆钟芯、儿童路线图 | 四十三分钟循环来自当夜撤离与警报中断 |
| 归还路径 | 返程票、住户证词、完整遇难名单、重绘母版 | 姓名、地点与幸存者选择必须一起恢复 |

### 人物与状态

首批 9 名人物分属水务委员会、夜渡船、河下住户与档案看守四方。至少包含：仍替委员会修正文书的书记官、保存返程票的船夫、拒绝被宣布死亡的幸存者、当年签字的退休工程师、维护盐版的档案员、困在循环中的住户代表，以及一名只在两入口证词互相印证后才承认身份的知情人。人物沿用 `unknown / wary / helpful / hostile / rescued / lost / transformed` 的存档枚举，但界面按案件展示为“未见／避谈／协助／阻挠／已送返／已失联／被回潮改写”。

### 回潮阶段

| 阶段 | 名称 | 调查便利 | 代价 |
|---:|---|---|---|
| 0 | 名字干燥 | 现行档案仍完全承认调查者 | 无 |
| 1 | 页边返潮 | 能看见被擦除的浅痕 | 个人签名开始洇开 |
| 2 | 门牌记得 | 河下街屋更容易显影 | 现住址偶尔被写成旧门牌 |
| 3 | 借来的归处 | 可以听懂循环住户的路线暗语 | 城市柜台需要再次确认身份 |
| 4 | 错位签名 | 能打开只认旧姓名的档案抽屉 | 行动记录出现别人的笔迹 |
| 5 | 名册回声 | 能让一名住户短暂离开循环 | 自己的名字会从一份现行表格消失 |
| 6 | 两处同时登记 | 可同时进入街屋与记录室的重叠空间 | 同伴对调查者的来历产生不同记忆 |
| 7 | 名册之外 | 能触碰完整重绘母版 | 若不在结案时归还身份，调查者也会成为待归档姓名 |

### 四种收场

- **把名单钉回市政厅**：公开工程账簿与完整名单，迫使城市承认责任；代价是部分幸存者失去匿名保护。
- **让夜渡船先送人回家**：优先用返程票和母版解开循环，让住户自行决定是否公开；责任追究被延后。
- **封死第七码头**：关闭重现路径并保护现行城区，受害者姓名继续留在盐版中；这是可解释但并不正义的封存。
- **让河下区重回地图**：同时取得原始账簿、完整名单、住户选择和重绘母版，恢复街区而不替幸存者公开私人去向；要求最高但仍留下城市赔偿与安置的长期代价。

## 美术比较与方向

现有视觉可分为三种互补语法：

1. **核心横幅**：深海军蓝、雨夜、电影式空间和大面积留黑，适合交接、夜行与结案。
2. **档案版画**：暖纸底、编辑蚀刻、职业道具和清晰轮廓，适合人物、地点、物件与手札。
3. **代码原生场景**：地图、档案钉、状态刻度与路线动效，信息密度最高，也最适合沙盒案件。

新案不追求每个行动一张电影插画。地图和状态继续由 HTML/CSS 承担，首批资产聚焦一张 2:1 河下街区主画面、三张关键地点版画与三张核心人物档案肖像；其余地点先使用统一纸本印章与地图符号。全部资产沿用 Ink Black、Deep Navy、Paper Beige、Amber、Oxidized Copper 与 Old Wine Red，不模仿《黑水溪》原模组版式、插图或任何可识别视觉构图。

首批资产槽位预先冻结，避免生成后才反推用途：

- `sandbox.tide.hero`：2:1 河下街区退潮主画面，用于入口与结案；左侧保留委托文案，右侧表现门牌从水面显影。
- `sandbox.tide.location.floodgate`：3:2 第七泄洪闸，强调黄铜刻度、反向潮痕和无人值守的控制台。
- `sandbox.tide.location.salt-archive`：3:2 盐蚀档案馆，强调纸、盐晶、压印底版和不可读姓名，不画可辨认文字。
- `sandbox.tide.location.low-tide-records`：3:2 低潮记录室，强调重绘母版、河水投影和四十三分钟刻度。
- 三张 4:5 核心人物肖像：夜渡船夫、退休工程师、盐版档案员；职业道具承担身份区分。

## 验收标准

- 两个入口在初始地点、物品、线索和接触方式上确实不同，但都能发现完整核心真相并抵达至少两个非失败收场。
- 七个地点可以非线性显影；关键事实均有至少两条独立证据路径。
- 相同入口、历史与行动始终产生相同结果；刷新晨报不重复结算。
- “回潮”只来自案内明确行动并显示来源，不与真实睡眠或健康信号绑定。
- 四个结局分别回应“公开名单、保护住户、封存街区、让河下街区重新被承认”的不同代价，不存在单一评分最优解。
- 新案与前三案存档完全隔离；重置只影响 `case-004`。
- 首批画面在桌面和移动端保持暖纸蚀刻统一语法，地图信息不依赖图片才能理解。
- 作品说明可以公开写明结构上向《黑水溪》的开放调查设计致敬，同时不存在其专名、情节、文本或视觉素材复用。
