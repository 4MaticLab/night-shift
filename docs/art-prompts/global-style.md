# 全局美术 Prompt

Original literary storybook noir illustration for an indie mystery web game. Quiet nocturnal city with civic personality, deep navy, soot black, warm amber lights, oxidized copper and old wine accents, archival paper texture, editorial engraving details, clean silhouettes, gentle lighting, melancholic but comforting, uncanny without horror. No photorealism, neon cyberpunk, anime exaggeration, copied game iconography, trademarked characters, slapstick cartoon or watermark.
