# 《千早诺亚的第十三次旅行》故事圣经

本文件固定 CASE 004 的人物关系、案件因果和结局边界。运行时生成能力、睡眠硬件、好友线索、密文与玩家路线只能丰富叙事，不得改写这些事实。

## 核心谜面

日本游学生千早诺亚在没有离境记录的情况下连续十二次合法进入雾灯城。十二份档案的日期、行李和纸张都不同，指纹却全部有效；第十三张车票甚至要到明天才发售。城市想把矛盾压成真假鉴定，诺亚只要求事务所在第十三次抵达前证明：互相冲突的记忆不等于有人说谎。

## 固定真相

- 千早诺亚连续十二次走完返照路线；每次城市重置都留下了一位真实生活过的诺亚，不存在可由仪器辨认的赝品。
- 十二位旧诺亚被现实排入未成线，在那里继续拥有住址、工作、债务、关系和选择。
- 终灯会只拼凑出返照仪式的机械部分：千早家镜片、铁路时序与城市地图。它对器物来路和文化语境的抹除没有让机器失效，只移除了伦理边界。
- 仪式不会自动识别唯一真身。它必须让一名外部观察者宣布“谁是原本”，再把其余连续人生从主城排除。
- 零号钥匙能为十三份签名分别开门，不会替使用者排序。案件的最终问题是由谁决定名字、出口和公开边界，而不是谁最像原本。

## 五夜节奏

1. **明日才抵达的委托人**：核对十二份合法入境章、十三张学校照片与明日车票。
2. **两个都记得昨夜的人**：沿十二种纸结与重写街图证明不同版本各自走过完整路线。
3. **拱灯学会的假东方**：拆穿收藏目录的错译与猎奇表演，取得返照镜片和未成线站台图。
4. **未成线的十二个地址**：确认十二位旧诺亚拥有连续生活，并查明观察者席才是排除开关。
5. **拒绝唯一原本**：十三位诺亚分别签下名字、去向和沉默权；玩家决定公开、封存或完整归还决定权。

## 关键人物

- **千早诺亚**：日本游学生与返照路线继承人。她主动调查事务所，不是等待营救的目标，也不是跨案件加成伙伴。
- **艾瑞丝·贝尔**：寄宿学校见证人，能分别说出十三段校园生活；她拒绝用行政日期否定具体记忆。
- **阿瑟·维尔**：终灯会馆长，明知译注是拼凑物，仍相信“可用性”足以替代器物和当事人的原意。
- **第六条路线的诺亚**：未成线测绘员。她不争夺原本身份，只要求自己有权选择不同名字。

## 三条核心推理

- `twelve-entry-stamps + paper-knot-route`：每次重置都留下了一位真实旅行者。
- `mirror-shard-memory + unmade-address-book`：未成线中的诺亚仍拥有连续生活，不是虚假倒影。
- `observer-chair-log + thirteen-signed-tickets`：抹除来自观察者裁决，不来自镜子辨认真伪。

## 返照镜台

可选密文依次确认 `13 ARRIVALS`、`13 LIVES` 与 `OBSERVER`，最终按 `ARRIVALS → LIVES → RIGHT` 把事实接回零号门。第一关使用数据驱动的计数刻度，其余关卡和最终接线继续使用通用密文契约。返照镜台只重排已经取得的证据，不解锁主线、奖励或结局。

## 三种结局

- **公开十三次抵达**：摧毁终灯会的秘密裁决，却让十三个人同时承受警方、报纸和猎奇目光。
- **封存返照档案**：先争取安全和撤离时间，但事务所仍代替当事人保管名字与解封时机。
- **把名字还给十三个人**：真结局。林渡离开观察者席，每位诺亚自行决定名字、出口和公开边界，仪式不再能排除任何人。
