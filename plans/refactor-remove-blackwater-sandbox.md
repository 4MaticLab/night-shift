# 移除黑水溪独立沙盒

- 状态：`in_progress`
- 优先级：P0
- 创建：2026-07-24
- 更新：2026-07-24
- 负责人：Codex
- 分支：`refactor/remove-blackwater-sandbox`
- 依赖：无
- 推进模式：`manual`

## 动机

Night Shift 的核心承诺是“玩家睡着以后，侦探替玩家工作”，案件可以更换，但白天判断、睡前交接、夜间自主调查和清晨归报必须属于同一产品生命周期。《黑水溪》当前以独立身份、地点沙盒、独立导航和独立存档运行，只复用了 `SleepSession` 与硬件边界，实际是嵌入案件书架的另一款游戏，削弱了系列身份。

## 范围

- 从案件注册表、首页书架、运行时分支和分享边界中移除 CASE 003。
- 删除黑水溪内容数据、独立沙盒引擎、存档、UI 与死样式。
- 删除黑水溪专属自动化路径并保留前两案完整覆盖。
- 把不再成立的稳定改编文档退役为历史墓碑，更新产品、架构、创作、质量与决策记录。
- 保留 legacy 计划与 Git 历史，确保删除内容可恢复和审计。

## 非目标

- 不把黑水溪重新改写为线性 Night Shift 案件。
- 不改变 CASE 001／002 的剧情、存档或生命周期。
- 不删除用户浏览器中已经存在的旧沙盒 localStorage；应用不再读取它。
- 不在本任务创作新的第三案。
- 不直接向 `main` 推送。

## 验收标准

- 首页案件书架只展示两宗符合 Night Shift 生命周期的案件。
- 生产代码不再包含 `sandbox-expedition`、黑水溪内容、独立沙盒状态机或沙盒 UI。
- CASE 001／002 的开始、切换、五夜循环、推理、分享、硬件与结局路径全部通过。
- 稳定文档不再把黑水溪描述为当前能力，决策记录保留撤销原因。
- 删除内容仍可从 Git 历史恢复。
