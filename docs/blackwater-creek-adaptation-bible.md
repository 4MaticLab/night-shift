# 《黑水溪》交互改编圣经

## 定位与发行边界

`case-003` 是 Night Shift 首个 `sandbox-expedition` 案件。它把 Scott Dorward 的《Blackwater Creek》整理成一份 1926 年“异地封存卷宗”：玩家不是扮演林渡，而是从密斯卡托尼克大学搜救队或波士顿私酒贩小队中选择一支调查队，在九个地点间自行决定调查顺序。

本实现是忠实、非商业的学习项目。仓库只保存重新编写的交互摘要、确定性规则和原创界面，不保存用户提供的 PDF、扫描页、原插图、完整译文或大段原文。案内持续显示原作者 Scott Dorward、译者埃兰迪斯、改编性质与非商业限制。2026-07-23，项目负责人确认当前纳入仓库的内容均可公开披露，并批准公开源码与既有 Vercel 自动部署；未来商业发行及新增原作资产仍属于独立的 G4 人工门槛，必须另行复核底层作品的数字游戏发行权。如果授权不足，应保留玩法骨架并进行全面原创化同构改写。

## 玩家身份与行动循环

两条入口共享同一世界真相，但初始资源、目的和接触方式不同：

| 入口 | 初始目的 | 初始优势 | 主要风险 |
|---|---|---|---|
| 大学搜救队 | 找回亨利与阿比盖尔·罗德斯 | 介绍信、考古野外包、失联线索 | 容易把超自然事故当成可归档的学术问题 |
| 私酒贩小队 | 查明并接管异常畅销的酒源 | 现金、左轮、汽车、酒类市场情报 | 容易把传播链当成一门可以接手的生意 |

一次行动遵循固定循环：

```text
选择已显影地点 → 阅读场景、意图、风险与前置条件
→ 写入今晚交接单并选择随队物品 → 调查队在夜间继续行动
→ 清晨拆开确定性晨报 → 归档证物／手札／物品与世界变化
→ 回到地图，决定继续调查或收场
```

夜班支持 12 秒 Demo 和可关闭页面后恢复的真实等待。行动没有隐藏骰点；等待时长与睡眠质量只改变夜间路线和晨报的叙事丰富度，不改变证物、污染、威胁、NPC 或结局。相同入口、证物、物品和已完成行动始终得到相同结果；危险来自玩家在已知风险下作出的决定。条件不足时行动保持锁定并解释所需准备。失败会开启新局面或明确进入终局，不会无提示清空存档。

## 改编覆盖矩阵

| 原模组结构 | Night Shift 表达 | 处理 | 验收证据 |
|---|---|---|---|
| 大学与私酒贩双开场 | 两个 `SandboxOrigin` | 保留并交互化 | 两入口拥有不同物品、线索与可达地点 |
| 黑水溪九个地点 | 可显影、可回访的地点图 | 保留并重新绘制 | 地图含镇、贾维农场、罗德斯营地、溪流、树林、挖掘地、干河床、卡莫迪农场、洞穴 |
| 地点内自由调查 | 每地点三至四个确定性行动 | 交互化 | 条件／效果由通用结算器处理，不按案件 ID 写组件分支 |
| 关键人物与阵营 | 12 份人物档案与可变状态 | 保留并合并桌游即兴空间 | 人物可处于未知、戒备、协助、敌对、获救、失落或异变 |
| 六份展示材料 | 六份可打开、归档的手札 | 摘要化重写 | 不复制长段原文，保留信息功能与来源 |
| “母神赠礼”渐变 | 0–7 污染轨道 | 保留并可视化 | 每次暴露写入来源，阶段同时说明诱惑与代价 |
| 调查、交涉、潜入、追逐与冲突 | 安静、暴露、危险、终局四级风险 | 合并为统一风险界面 | 交接前可读风险，清晨写入行动日志 |
| 卡莫迪生意与山中会众 | 威胁时钟、NPC 状态、货单与库存行动 | 交互化 | 农场、洞穴和传播链可分别处理 |
| 开放式收场 | 五种状态化结局 | 保留并扩展 | 农场覆灭、撤离、交易、暂时封存、摧毁源头 |
| 身体恐怖 | 默认描写与低刺激替代表达 | 保留事实、调整呈现 | 低刺激模式不隐藏线索、不改变行动或结局可达性 |

## 固定真相与线索冗余

以下因果不能被随机、生成文本或玩家访问顺序改变：

- 阿比盖尔已经与溪源中的存在融合，溪水重新出现与此直接相关。
- 黑水沿灌溉、玉米、牲畜和威士忌形成传播链；只处理洞穴或只处理农场都可能留下后果。
- 卡莫迪兄弟利用变化牟利，斯普劳尔斯顿则希望独占山中“母亲”的眷顾；两股势力并非同盟。
- 亨利仍可能被救出，但获救不等于恢复；他的笔记是洞穴、阿比盖尔与污染阶段的重要交叉证据。
- 源头能被封住或摧毁；封洞是暂时控制，摧毁需要炸药和对阿比盖尔处境的可靠认识。

20 条核心证物通过相互引用形成网状档案。洞穴位置可由营地摘记、挖掘记录、干河床或溪流调查显影；污染传播可由兽医证词、农场边界、灌溉水路、货单或活水样本确认；阿比盖尔的真相可由笔记、河床沉积或进入洞穴交叉确认。单次错过不会形成核心事实死锁。

## 状态与确定性规则

沙盒存档使用独立的 `night-shift-sandbox-v1`，按案件 ID 保存：

- 入口、已显影／已访问地点和已完成行动；
- 证物、手札与物品；
- 0–7 污染、0–6 威胁；
- 12 名 NPC 的当前状态；
- `day | night | morning` 阶段、待执行行动、随队物品与核心 `SleepSession`；
- 最后一份晨报差异快照、有来源的行动日志、低刺激设置与已选择结局。

持久化结构为 v2，并把缺少阶段字段的 v1 存档安全归一化为白天；有效的夜班与晨报则可以在刷新后继续。它与线性案件的 `night-shift-save-v1` v14 分开持久化。这样无需让前两案承担不适用的地点、污染和 NPC 字段，也避免沙盒状态污染五夜循环。`CampaignManifest.format` 决定页面进入 `linear-night` 或 `sandbox-expedition`；沙盒数据仍在 manifest 注册时执行引用完整性校验。

## 污染、威胁与内容安全

污染只来自故事内明确标注的饮用、样本接触、梦境暴露或进入源头。真实时间、睡眠质量、登录频率和设备状态都不参与污染。界面始终显示当前阶段及最近行动的增量，不把身体变化伪装成奖励分数。

低刺激模式会把具体身体病变、生产与吞噬描写换成较抽象的黑色花纹、异常愈合和边界感丧失；证物、条件、数值与结局完全相同。案件入口提前展示身体恐怖、成瘾／污染、动物异常和人物失控等内容警告。原型不使用闪烁和突发音效。

## 结局矩阵

| 结局 | 清晰条件 | 意义 |
|---|---|---|
| 玉米地合拢 | 选择无准备强攻农场 | 终局失败，传播链仍在 |
| 从北坡离开 | 取得足以撤离的路线或真相 | 幸存并带走证词，但山谷继续变化 |
| 接管威士忌生意 | 私酒贩完成与达米恩的交易 | 得到生意，同时主动扩大污染 |
| 封洞并烧掉库存 | 破坏库存并封闭洞口 | 切断当前传播，源头仍可能再醒 |
| 让溪流第一次安静 | 取得炸药、确认阿比盖尔真相并摧毁源头 | 终止孕育，但无法抹去既有受害者与外泄 |

终局结算后存档不被删除。玩家可以重看证物、人物、污染记录和行动履历，再返回同一结局；“重新调查”仅重置 `case-003`，并保留低刺激偏好。

## 视觉与声音边界

首版使用原创 CSS 绘制的九地点档案地图、纸本手札、污染刻度、人物卷宗和结案桌，沿用 Night Shift 的暖纸、墨绿、锈红与编辑蚀刻语言，但不复刻 PDF 版式或插图。专属人物肖像、场景插图和环境音批次推迟到 G4 授权复核之后；当前原型的玩法、信息层级与无障碍不依赖这些资产。

夜间探索复用核心城市路线图、城市时辰和交接离手语义，但将路线节点替换为临时营地、目标地点、行动与晨报桌。清晨页面使用独立的差异报告，只展示这一夜新增的证物、手札、物品、地点与 NPC 变化；刷新晨报不会重复结算。
