# 90 秒现场演示

1. 0–15 秒：主页说明“你睡着以后，他才开始工作”，点击“开始第一宗案件”。
2. 15–35 秒：三幕开场后选择“让纸张先开口”，再带上“黄铜侧照灯”，点击“今晚交给你了”。夜间展示逐渐显影的第一枚夜印。
3. 35–55 秒：晨报先展示新夜印和随身物回响，再展示路线、侦探日志、旧车票与“七年旧纸 / 昨天日期”的矛盾。
4. 55–75 秒：用底部导航打开案件板，选择“四十三天”和“未寄出的明信片”，建立连接并确认“米娜知道伊芙琳仍然活着”。
5. 75–90 秒：按 Shift+D 打开 Demo，选择“跳到真结局条件”，完成第五夜并展示真结局。

## 真实夜班补充演示

若需要说明长期玩法，在第二步切换到“今夜真实交接”，开始后刷新页面：夜班页面会按原交接时间恢复。点击“我醒了，拆开报告”后，晨报会展示实际记录时长；提前结束仍会获得主线线索。
