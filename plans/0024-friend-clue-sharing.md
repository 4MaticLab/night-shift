## 动机

玩家希望把自己案件板上的一张线索送给好友：分享端显示二维码，好友扫码后通过带 query 的网页进入游戏，并把对应线索放进自己的本地案件板。这是一种无需账号、房间或实时服务器的轻量异步联机，也符合游戏“错开时间仍能互相留下东西”的核心气质。

## 范围

- 在已解锁证物的档案侧页提供“送给好友”入口。
- 生成包含当前线上来源和稳定线索 ID 的分享 URL、二维码与复制链接动作。
- 页面启动时读取并严格校验线索 query；合法线索写入好友本地案件板并保留“好友送达”来源。
- 接收后直接给出清楚的成功、已拥有或无效链接反馈，并允许进入案件板查看。
- 保持无登录、无后端、无 API Key 的 local-first 行为。
- 覆盖二维码内容、复制链接、首次接收、重复接收、非法 ID 与旧存档迁移。

## 非目标

- 不实现实时房间、好友列表、聊天、账号体系或跨设备云存档。
- 不允许分享不存在的线索、动态文案或任意外部 URL。
- 不让分享线索自动确认核心推论、推进章节或改变结局资格。
- 不上传玩家存档、选择历史或其他本地数据。

## 验收标准

- 已解锁线索可以生成可扫描二维码，二维码内容与复制链接完全一致。
- 新浏览器打开合法分享链接后，对应线索进入案件板并标记“好友送达”。
- 重复打开同一链接不重复写入；非法或未知线索 ID 不改变存档。
- 接收线索不会推进夜数、生成其他奖励或直接确认推论。
- 桌面与 390 × 844 都能完成分享和接收，二维码不溢出或被底部导航遮挡。
