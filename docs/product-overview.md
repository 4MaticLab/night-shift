# 产品概览

## 一句话定位

《夜班侦探 Night Shift》是一款与你轮班生活的异步侦探游戏：玩家白天分析线索并安排方向，睡着以后，侦探林渡替玩家进入城市调查。

核心情绪不是睡眠管理，而是：**我想早点睡，因为我想知道侦探今晚会发现什么。**

长期叙事、玩法与美术方向见 [[docs/north-star]]。

## 核心循环

```text
晨间报告 → 白天推理 → 选择方向与随身物 → 睡前交接
    ↑                                  ↓
获得线索、藏品与矛盾 ← 夜间城市调查 ← 玩家休息
```

每次睡眠都推进主线。睡眠较短时路线更短但仍有关键发现；稳定、充足的睡眠带来环境观察、支线信息和更多收藏，而不是简单分数。每夜三个调查方向会改变林渡先去哪里、沿途遇见哪条城市规矩以及寄回哪封路线来信，但不会改变必得线索；随身物则改变他注意到什么、谁愿意开口和明信片背面的附言。第一夜归来后的白天，门缝下还会出现三张稳定的城市告示：玩家可回应一张，也可全部收起；选择会在下一份晨报留下一句回声并进入剪报册，但没有行动点、奖励差或主线门槛。每个方向还会惊动错页登记处、失物领事馆或熄灯测绘社之一：社团跨夜记住玩家的做事方式，逐步更换称呼与来函礼数，并提出没有标准答案的小型问函。玩家可以选择两种答复，也可以不回信；同一社团下次会引用最近一次回答，但不存在公开声望点数、最优兑换路线或结局门槛。移动晨报把这些路线、时辰、植物、人物和社团旁支收进明确的“可选详读”，核心日志、路线、新证物、矛盾与下一步始终保持在主文档流；桌面仍默认展开完整档案。

白天的案件板是一座可检索的证物档案库：每张卡都能直接打开完整详情、城市异议与林渡批注；当组成某条推论的证物全部到齐，推理合成台会列出这组输入，玩家明确整理后把推论作为新档案归档。推论还可成为后续配方的输入，因此保留主动推理节奏而无需穷举错误配对。桌面以档案库／推理台双栏展示，移动端把推理台和单列档案放回自然滚动。可选密文台位于主推理之后并默认收起，避免把补充解密误解为主线门槛。调查页只复用现有纸张、黄铜、墨色、蝴蝶封印和字体资产，不改变 Night Shift 的美术语言。

等待过程中，一株章节专属的夜生植物会从种核、抽芽、展叶长到开花；提前醒来只得到较小但完整的植株，不存在枯死惩罚。真实夜班若只是短暂醒转，玩家可以留下每夜最多一次的“睡隙记录”再继续休息；城市会回寄一段声音、掠影和林渡短笺，同夜不可反复收集，也不改变任何评价或成果。每次完成的等待都会形成一枚“夜印”、一株温室标本，寄回一张城市明信片，并让口袋里多出一件无法精确指定的城市小物。纪念物由存档种子、方向、随身物与既有历史稳定决定，五夜不重复、刷新不重抽，也没有稀有度或案件优势。第二至第五夜还会让一位关键人物进入晨报；收藏页按相遇与现有证物逐层展开其档案，把城市的秘密重新落到有表情、也有保留的人身上。晨报与收藏页共同保存标本、路线、答复、城市人情、口袋小物、人物档案、睡隙回声和午后剪报。收藏页用“核心物证、夜班归来、城市回声、口袋小物”四个档案组解释这些内容的关系：核心物证与可选 Injective 回执永远优先，桌面仍可连续阅览全部陈列，平板与手机一次只聚焦一个档案组。结案时，三个选择各有独立的林渡终函；页面会把当前存档真实走过的五夜路线、随身物、植物、纪念物与核心物证重新编成归来总账，并允许在不重置结局的情况下回看案件档案。

晨报阅读与白天推进彼此独立。刚归来的报纸可以直接进入案件板阅档、合成推论，再回「今晨」继续阅读同一份内容；只有明确点击“结束今日，准备下一夜”才推进章节。进入下一夜的白天后，「今晨」仍会从既有方向、随身物、质量、时辰、社团与纪念物历史重放最新晨报，刷新也不会把它替换成空归档页。重读只投影已存在的存档快照，不复制线索或重复结算。

案件板上的已解锁证物还可以单独“送给好友”：游戏生成只含稳定线索 ID 的二维码与链接，好友扫码后把该证物放进自己的本地案件板并标记为“好友送达”。分享不需要账号或服务器，也不携带夜班进度、选择历史和其他存档内容；好友仍需亲自完成推论合成，且赠送线索不会直接满足真结局资格。

四案各有一张案件专属密文台。首案第一关不是文本填空：玩家要把隐藏站钟从 00:34 亲手调到 00:43；后续再解开花店字母码和隐藏站台时刻表。第二案第一关则把雨中调频仪从 96.9 调到 97.3 MHz，再通过沉默来电户数与摩尔斯尾音还原居民信号。第三案依次确认每日数量 `13`、火灾方向“市政热力主管”和公共权利代码 `COMMON`。第四案的返照镜台把十二份入境记录与一张明日票对齐为 `13 ARRIVALS`，再确认 `13 LIVES` 与 `OBSERVER`。刻度盘会以静默、微弱、清晰和已锁定提供接近反馈，但错误锁定没有惩罚。三段答案全部归档后，还要通过点击排序完成最终接线：首案按 `WHEN → WHO → WHERE`，第二案按 `SENDER → CHANNEL → MESSAGE`，第三案按 `CAUSE → OWNERS → RIGHT`，第四案按 `ARRIVALS → LIVES → RIGHT`。解密只留下补充旁注、本地档案印章和完成回执，不替代推论合成，也不改变线索、睡眠评价、奖励或结局资格。

睡前交接发生在林渡的近距离桌前：玩家选定方向和随身物后，“今晚交接单”会把调查姿态、目的地和带走的东西写到他的肖像旁，明确这是把任务托付给一个会自行行动的人，而不是填写睡眠表单。交接提供两种节奏：Demo 把一夜压缩成 12 秒并固定为夜半时分，便于现场稳定理解循环；真实夜班从交接时刻开始记录，允许玩家锁屏或关闭页面，醒来再按实际时长拆开晨报。真实交接还会按设备本地时间落入掌灯、夜半、末更或白昼小憩；每夜四个时辰分别改变城市侧影、偶遇与林渡短笺，并进入晨报和城市值更簿，但不改变线索、收藏、植物、睡眠评价或结局资格。两种模式共享同一故事结算规则。Demo 控制台本身是只读入口：打开、浏览或关闭不会启动案件；章节、完整案件板、真结局快照和重置只有在逐项说明影响并确认后才会改写当前案件，其他案件的独立存档不受影响。

睡眠硬件是这段交接的可选感官层。玩家可以授权虚拟戒指、手表、床垫感应带或智能枕，在夜行中看到确定性模拟信号，并在晨报收到只保留摘要的感官回执；不接设备或撤销授权都不影响故事。Apple Health、Health Connect、Oura 与 Fitbit 当前只提供明确标注的桥接预演，不会伪装成真实连接。实现与隐私边界见 [[docs/sleep-hardware-bridge]] 和 [[docs/privacy-and-guardrails]]。

交接还提供一项可选的“放下纸条”休息仪式：玩家写下一件今晚可以暂时不解决的事，清晨会收到林渡的短笺。纸条默认只保存在当前案件的浏览器本地存档；只有玩家取得部署者访问授权并逐夜主动选择 AI 个性化时，才把这一张纸条与本夜地点、方向、随身物和侦探名发送到服务端模型端点。模型只从固定语气和意象枚举中选择，短笺正文由安全模板组合，不接受自由模型文本。未配置、权限失效、请求失败或输出无效时立即使用确定性本地回信。无论来源如何，短笺都不进入线索、睡眠质量、奖励或结局计算。

## 当前案件库

同一客户端可以从案件书架切换剧本，并为每案保留独立本地进度。《零点四十三分的末班车》是全新存档、无效存档和首页推荐的默认起点；已经开始另一案件的玩家仍会保留并继续当前卷宗，不会在返回首页时被隐式切换。首页以一张当前案件主卷宗和可横向浏览的次级入口表达这条层级，切换不会覆盖各案进度。《零点四十三分的末班车》包含五夜剧情、12 条核心线索、8 件收藏品与三个结局，并可在案件书架切换为完整英文版；首次访问会从偏好 Cookie 或浏览器语言直接选择中英文首帧，手动切换刷新后保留，但语言只改变展示文本，不复制或重置案件存档。《只在雨中播出的电台》《黎明前出炉的第十三个面包》和《千早诺亚的第十三次旅行》都使用同一五夜循环，各有 12 条线索、8 件收藏品、三条推理与三个独立结局。后两案各使用 34 张专属美术，分别表现十二人合作社与十三段被现实排除的人生。后三案当前都明确标记为仅中文。

已解锁的核心收藏品可以选择性领取为 Injective EVM Testnet ERC-721 纪念凭证。该入口只是一张公开链上档案回执：不连接钱包、不配置环境变量或交易失败时仍可完整玩完五夜；NFT 不证明链下通关、不改变收藏解锁、结局资格或任何睡眠评价。详见 [[docs/injective-keepsake-mint]]。

案件库只接纳同一个 Night Shift 生命周期：玩家在白天读报告、整理证物并决定方向，林渡在玩家休息时外出，清晨留下确定性的调查结果。题材、人物、谜面和城市区域可以更换，但不能通过案件包替换角色关系、另起独立导航或绕开这套交接—等待—晨报结构。

未开封案件不会从书架直接跳到睡前准备。每案都先以三幕专属序章交代异象、委托／证物与林渡的首夜目标，玩家明确“接下案件”后才进入事务所和今夜交接；已开始的案件继续原存档时不强制重播。这段导入与正文一样由案件包提供确定性文字和已登记美术，但不产生选择、奖励或隐藏状态。

## 成功标准

- 15 秒内让新玩家理解“你睡着时侦探工作”。
- 60–90 秒内演示完整的交接、夜间调查、晨报和推理循环。
- 无后端、登录、环境变量或 API Key 时可完整体验。
- 国际玩家可以用英文独立完成首案的交接、晨报、推理与结局。
- 睡眠差异增加叙事丰富度，不惩罚玩家。
- 美术统一为温暖故事书黑色电影，参见 [[docs/art-direction]]。

## 非目标

本项目不是医疗产品、睡眠评分工具、健康仪表盘、开放式聊天机器人、签到积分应用、随机故事生成器或 NFT 投资／交易产品。当前版本不建设登录、云存档、数据库、支付、实时多人房间或远程可执行剧本；睡眠设备仅有本地虚拟样机，真实厂商 SDK、OAuth 和云端令牌服务尚未接入。好友线索只是一条 local-first 异步深链接；AI 只在部署授权与逐夜同意后选择单张晨间短笺的受限风格。Injective 功能只使用测试网并由玩家自愿发起，不承诺价值、稀有度、版税或游戏优势。
